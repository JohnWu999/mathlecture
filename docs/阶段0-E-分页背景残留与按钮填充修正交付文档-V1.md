## 1. 本轮反馈

犟爸确认阶段0-D分页视觉进步很大，同时提出两个进入下一阶段前必须收口的问题：

1. 分页背景是否仍残留旧版本背景，需要检查旧代码是否没有清理干净；
2. 分页按钮框是否仍残留旧版本，有些按钮框背景色不能完全填充按钮框。

结论：反馈成立。代码中确实还存在 Stage0-B 的旧分页背景定义和旧 `hand-btn::before` 手绘内边框逻辑。虽然 Stage0-D 后置样式已经覆盖了大部分显示效果，但从代码和风险角度看，仍属于“旧代码残留”，可能造成局部页面或按钮状态出现不一致。

## 2. 已定位的问题

### 2.1 旧分页背景残留

文件：`app/globals.css`

残留位置：阶段0-B旧定义：

- `.forest-page-shell` 中仍保留旧米色纸面渐变：`#fbfbf2` → `#f7f0df`；
- `.forest-page-shell::before` 中仍保留固定数学符号背景：`∞ △ + 7 ⟂ ○`；
- 后面的 Stage0-D 样式虽覆盖了它，但旧定义仍在，容易造成维护混乱或局部回退。

处理：

- 将旧 Stage0-B 背景替换为 `background: none`；
- 将旧固定符号内容清空；
- 新增 Stage0-E 强制规则：分页背景只以 V2 Morning Paper / Forest Ink / mist grid 为准。

### 2.2 按钮背景不能完全填满按钮框

残留原因：

- 旧 `.hand-btn::before` 会生成一个绝对定位的手绘内边框；
- 新 V2 胶囊按钮改为圆角胶囊后，旧伪元素仍可能形成“边框里有一圈没被背景填满”的视觉错觉；
- 一些按钮使用 `bg-crayon-green/70` 等 Tailwind opacity variant，原先 `.bg-crayon-green` 选择器不能覆盖带 `/70` 的 class。

处理：

- `.hand-btn` 增加：
  - `overflow: hidden !important;`
  - `background-clip: border-box !important;`
  - 统一胶囊圆角；
- `.hand-btn::before` 禁用：
  - `display: none !important;`
  - `content: none !important;`
- 增加属性选择器强制填充：
  - `.hand-btn[class*="bg-crayon-green"]`
  - `.hand-btn[class*="bg-crayon-yellow"]`
  - `.hand-btn[class*="bg-crayon-blue"]`
- 白色按钮也统一补足纸面填充：`.hand-btn.bg-white`。
