# 阶段1-F｜个人中心唯一入口导航修正交付 V0

时间：2026-06-09 08:35 CST
线上地址：http://159.75.144.28/math-young-lecturer

## 1. 用户反馈

学习者、老师、管理者登录后，导航栏又新增了【个人中心】、【老师工作台】、【管理员后台】按钮。用户判断这些入口会让导航栏再次变复杂，建议删除新增角色按钮，直接把原有【个人中心】作为唯一入口。

## 2. 修正原则

本轮按“导航栏简洁 + 身份入口唯一”处理：

1. 顶部主导航仍保留公共页面：
   - 【你问我答】
   - 【项目营】
   - 【成果广场】
   - 【个人中心】
2. 不再在登录后追加第二组角色入口：
   - 不追加【老师工作台】；
   - 不追加【管理员后台】；
   - 不追加第二个【个人中心】。
3. 原有【个人中心】成为唯一身份入口，并按当前登录角色分流：
   - 学习者：进入 `/profile`，公网完整入口为 `/math-young-lecturer/profile`；
   - 老师：进入 `/teacher`；
   - 管理者：进入 `/admin`；
   - 未登录：仍进入 `/profile` 登录/成长护照引导链路。
4. 老师工作台、管理员后台页面和权限边界保留，只是不在导航栏额外露出独立按钮。

## 3. 代码改动

### 3.1 导航栏

文件：`components/navbar.tsx`

- 删除导航栏中用于追加角色工作台入口的 `workspaceLinks`；
- 公共链接改为 `baseLinks`，只包含【你问我答】、【项目营】、【成果广场】；
- 统一在 `links` 末尾追加一个且只有一个【个人中心】；
- 【个人中心】的 href 由 `getPersonalCenterHrefForRole(session?.user?.role)` 计算；
- 学习者 `/profile` 仍使用完整公网 basePath href，避免手机端旧 chunk / 客户端路由问题。

### 3.2 角色入口规则

文件：`lib/role-access-boundary-rules.mjs`

- `getVisibleWorkspaceNavForRole()` 对 STUDENT / TEACHER / ADMIN 均返回空数组；
- `getPersonalCenterHrefForRole()` 保留按角色分流：STUDENT -> `/profile`，TEACHER -> `/teacher`，ADMIN -> `/admin`，未登录 -> `/profile`。

### 3.3 防回归测试

新增/更新：

- `tests/stage1f-single-personal-entry-nav-rules.test.mjs`
- `tests/role-access-boundary-rules.test.mjs`
- `tests/stage1f-nav-workspace-ui-rules.test.mjs`

覆盖规则：

1. 登录后不追加角色工作台入口；
2. 老师/管理者仍通过唯一【个人中心】分流到自己的工作台；
3. 导航栏不再调用 `getVisibleWorkspaceNavForRole()` 生成第二组入口；
4. 保持之前删除独立【我要提问】按钮的简洁导航规则。
