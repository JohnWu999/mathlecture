# 积分规则展示与成长能量机制 V0

项目：数学小讲师联盟  
确认时间：2026-06-02 10:06 CST  
状态：犟爸已确认采纳，作为后续个人中心、成长护照、积分流水与项目卡开发依据  

---

## 一、本次归档结论

积分规则需要让孩子清楚理解：

1. 我的积分 / 成长能量从哪里来；
2. 它可以用来做什么；
3. 它不是公开排名，也不代表谁更聪明。

最终采用“四层展示结构”：

| 层级 | 展示位置 | 作用 | 规则 |
|---|---|---|---|
| 第一层 | 首页 | 不强调积分 | 首页只讲好问题、孩子讲孩子、项目探索、数学森林，不把第一印象做成积分平台 |
| 第二层 | 个人中心 / 成长护照 | 完整说明积分规则 | 作为主解释入口，孩子和家长可查看成长能量来源、用途、历史记录和说明 |
| 第三层 | 提问、认领讲题、项目报名、作品提交等行动页面 | 即时轻提示 | 用一句温暖提示告诉孩子本次行为会如何记录成长 |
| 第四层 | 家长视角 / 成长记录说明 | 防止误解 | 明确成长能量记录参与、表达、讲解、合作和探索，不做公开排名 |

---

## 二、命名建议

前台面向孩子不优先使用冷冰冰的“积分”二字，可采用：

> 我的成长能量

或：

> 我的数学成长能量

后台数据模型仍可使用 `PointTransaction`、`points`、`PointReason` 等工程命名，但前台儿童文案尽量表达为“成长能量”。

## 三、个人中心 / 成长护照中的完整规则

学习者个人中心应新增或强化一个模块：

> 我的数学成长能量

该模块包含：

### 3.1 当前成长能量

示例文案：

> 你现在有 120 点成长能量。  
> 这些能量来自你的提问、讲解、项目探索和认真反馈。

注意：

- 只对孩子本人、家长辅助视角、老师和管理员可见；
- 不在成果广场、排行榜、公开身份卡中展示；
- 不写“超过多少同学”“全站第几名”。

### 3.2 成长能量从哪里来

| 行为 | 前台解释 | 对应成长方向 |
|---|---|---|
| 提出一个清楚的问题 | 你把困惑说出来了，帮助更多同学一起思考 | 提问者 |
| 补充自己的困惑 | 你愿意说明哪里不明白 | 表达 / 真实思考 |
| 认领并完成一道讲题 | 你尝试把方法讲给别人听 | 小讲师 |
| 讲解通过老师审核 | 你的讲解数学正确、安全、基本清楚以上 | 小讲师 |
| 帮同学讲明白一个方法 | 你的讲解帮助别人理解 | 助人 / 讲清楚 |
| 参加项目并完成任务 | 你在真实任务里使用数学 | 探索家 |
| 提交项目成果 | 你把过程和发现留下来了 | 项目表达 |
| 给同学留下真诚反馈 | 你认真倾听并回应别人 | 合作 |

### 3.3 成长能量有什么用

成长能量用于三类事情：

1. **记录个人成长**：帮助孩子看到自己在哪些行为上持续参与；
2. **辅助项目准备度判断**：用于后台判断孩子是否适合参加某些项目，但公开项目卡不展示具体积分门槛；
3. **辅助身份 / 星级成长**：作为提问者、小讲师、探索家星级判断的参考因素之一。

明确排除：

- 不做公开排行榜；
- 不公开积分总数；
- 不直接用积分兑换身份星级；
- 不把能力徽章只绑定积分，能力徽章仍采用“老师能力标签累计 → 系统点亮”的规则；
- 不以物质奖励或强兑换刺激孩子刷分。

### 3.4 温和权益

如后续需要权益，可优先采用低焦虑权益：

- 优先选择某个项目主题；
- 获得一次老师的项目建议；
- 解锁数学森林中的小装饰；
- 获得一张专属成长海报；
- 选择一次“我想挑战的问题类型”。

不建议 MVP 阶段引入强物质奖励或兑换商城。

## 四、关键行动页面的即时提示

### 4.1 提交问题页

提示示例：

> 提出一个清楚的问题，也是在帮助更多同学学习。  
> 问题通过审核后，你会获得提问成长能量。

### 4.2 认领讲题页

提示示例：

> 完成讲解并通过审核后，你会获得小讲师成长能量。  
> 如果讲解帮助了同学理解，还可能点亮“讲清楚”能力徽章。

### 4.3 项目营卡片

项目卡不写：

> 需要 200 积分才能参加

改用：

> 你的准备度：可以尝试

或：

> 建议先完成一次小讲解，再来挑战这个项目。

底层可以参考积分和有效行为，但前台使用“准备度 / 参与条件”的低焦虑表达。

### 4.4 行为完成后的反馈提示

示例：

> 你认真把问题说清楚了，获得 5 点提问成长能量。  
> 好问题会让更多同学一起思考。

示例：

> 你的讲解通过审核了，获得 20 点小讲师成长能量。  
> 讲清楚一道题，就是帮一片数学森林长高一点。

## 五、家长视角说明

在家长辅助查看孩子成长记录时，应显示解释：

> 成长能量主要记录孩子的学习参与、表达、讲解、合作和项目探索，不用于公开排名，也不代表谁更聪明。

目的：避免家长把积分误解成刷题分数、竞争指标或平台排名。

后续开发应对应以下模块：

| 模块 | 开发要求 |
|---|---|
| 个人中心 | 增加“我的数学成长能量”模块，展示当前成长能量、来源说明、用途说明、积分流水入口 |

| 项目营 | 项目卡使用准备度/参与条件文案，不公开具体积分门槛 |
| 项目提交页 | 增加探索成长能量轻提示 |
| 家长说明 | 在成长护照或个人中心中补充反排名说明 |
| 后台 | 保留结构化 `PointTransaction`，确保 reasonCode/sourceType/sourceId 可回溯 |

## 七、反焦虑底线

最终底线：

> 成长能量只给孩子本人、家长辅助视角、老师和管理员看，不用于公开排名，也不代表谁更聪明。它只是记录孩子在提问、讲解、探索和帮助同学过程中的真实努力。

该规则与既有原则一致：公开区域可展示已授权作品、主身份徽章和星级，但不展示具体积分总数、后台能力标签和细颗粒成长数据。
