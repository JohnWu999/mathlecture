## 1. 关于 CTA：“看看孩子怎么学”是否改为“看孩子如何成长”

结论：**采纳，首页高保真 V0 改为“看孩子如何成长”。**

理由：

1. “看孩子如何成长”更呼应无限生长版的核心隐喻：问题发芽、讲解长高、项目成林。
2. 它比“看看孩子怎么学”更有情绪牵引，适合作为首页首屏的理解型 CTA。
3. 它不会改变原有功能含义：点击后仍跳转到首页内部的“成长路径/孩子怎么学”模块。

但需要注意：如果未来做投放页或家长首次认知页，可以在按钮下方或 hover/说明中补一句“从提问、讲题到项目探索”，避免“成长”过于抽象。

## 2. 首页高保真 V0 覆盖范围

本稿覆盖首页关键视觉区域：

1. 首页首屏 Hero；
2. ∞ 无限成长路径；
3. 一个问题的成长旅程；
4. 三种身份成长卡：提问者 / 小讲师 / 探索家；
5. 项目营森林任务卡；
6. 三类分享海报方向：好问题海报 / 小讲师封面 / 项目成果海报；
7. 底部再次转化 CTA。

---

## 3. 设计原则

- 不做普通教育网站的“卡片堆叠”；
- 不做课程电商货架；
- 不做游戏化闯关和排行榜；
- 用 ∞ 作为全站隐形秩序；
- 用“问题发芽 → 讲解长高 → 项目成林”解释孩子成长；
- 让孩子感到“我可以进入这个世界”，让家长感到“这里有教育可信度”。
