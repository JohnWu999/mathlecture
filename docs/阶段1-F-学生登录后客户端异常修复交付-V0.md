## 3. 根因

`app/profile/page.tsx` 在学生个人中心渲染“成长能量从哪里来 / 成长能量有什么用”两组列表时，使用了：

```tsx
GROWTH_ENERGY_SOURCES.map(...)
GROWTH_ENERGY_USES.map(...)
```

但该页面此前没有从 `@/lib/growth-passport-ui-rules.mjs` 显式导入这两个常量。

结果是：

1. 未登录或资料未加载完成时不会触发；
2. 学生账号登录成功并拿到 profile 数据后，页面开始渲染完整成长护照；
3. 浏览器端遇到未定义变量，触发客户端 `ReferenceError`；
4. Next.js 显示通用错误页：
   `Application error: a client-side exception has occurred`。

这也解释了为什么前几轮登录接口、session、profile API 都能验证通过，但用户手机端仍看到客户端异常页。
