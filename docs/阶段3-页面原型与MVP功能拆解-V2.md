## 二、阶段3 V2 反馈吸收清单

本 V2 相比 V1，重点吸收犟爸对阶段3 V1提出的12项反馈，并形成以下产品规则：

1. **低年级提问表单降难度**：问题标题不要求一二年级孩子自己概括；MVP采用“上传原题图片 + 系统/家长辅助生成标题 + 家长确认/可编辑”的方式。知识点与困惑描述采用下拉选择 + “其他，可编辑”。
2. **小讲师认领时限改为72小时**：给孩子与家庭留出更充足的拍摄、检查、上传时间。
3. **讲解分享范围改为两档**：A 只分享给出题人和加热度同学；B 愿意分享到成果广场，启发和鼓舞更多同学。
4. **项目反馈问卷改为节点式收集**：不在每个免费小项目后强制弹问卷；MVP建议完成/解锁5个项目后收集一次，后续可支持8个项目或主题项目包结束后收集。单个项目结束只保留轻量感受入口。
5. **个人中心增加“我的影响力”独立版块**：记录助人、合作、成果分享、邀请注册、被启发行为等数据；每个用户拥有邀请码/二维码，分享海报自动带注册二维码。
6. **首页导航与全站布局必须响应式**：手机端折叠导航；电脑/平板端完整导航；其他模块也按屏幕自适应排版。
7. **平台温暖数据区可增加星云式能力词**：围绕平台数据展示“画图表达、认真倾听、合作探索”等能力词；MVP先做静态/轻动画，复杂动态后置。
8. **全站文案以《教育的目的》为气质基底**：适合谁/不适合谁等文案必须避免空洞营销，强调真实经验、主动表达、合作探究、知识有生命。
9. **热度按钮增加说明弹框**：说明“如果你也有相同困惑，请为这道题增加热度”，避免误解成比赛或点赞。
10. **付费项目改为项目包/主题营形态**：MVP提供两个选择：5个小项目组成的主题项目包；20个小项目组成的长期探索计划。
11. **付费项目退费规则要人性化且保护小组权益**：项目开始后不支持无理由退费；特殊情况可延期、转入下一期、转为名额保留或按人工规则部分处理，避免影响其他小组成员。
12. **讲解视频使用统一封面模板**：只替换标题、知识点、小讲师昵称等文字，保留“数学小讲师联盟”Logo和统一视觉记忆点。管理员后台增加付费和退费记录，可MVP手工登记。

## 三、阶段2 V2 同步更新清单

阶段3 V1 已相比阶段3 V0同步以下阶段2 V2规则，V2继续保留：

1. 首页副标题改为“小学低年级孩子的数学共学社区”；标签为“小学1–3年级”。
2. MVP种子用户仍以小学一年级下到二年级上为主，但对外定位预留1–3年级空间。
3. “能力标签”在产品表达中改为“能力观察 / 成长能力记录 / 能力观察项”，避免“给孩子贴标签”的负面感。
4. 审核通过后增加站内通知，复杂推送系统后置。
5. 提交问题页面必须支持上传图片 / 拍照原题；题目图片进入问题题库，OCR/AI识别可后置。
6. 问题增加“我也有这个困惑 / 热度”机制，讲解发布后推送给提问者和加热度同学，小讲师帮助人数包含加热度人数。
7. 项目卡片增加解锁条件、组队状态、有效时长。
8. 免费基础项目也必须高水准；与付费项目区别在复杂程度、老师参与深度、反馈深度，而不是质量高低。
9. 项目成果提交形式细化：照片、短视频、语音+图片、简短文字、项目模板。
10. 结营证书展示孩子收获的能力。
11. 题目/项目认领后增加“请假退出”按钮，自动释放资源；付费项目退出规则需报名前明确。
12. 成果广场增加点赞鼓励和温暖行动号召，但不做排行榜。
13. 三个主身份初始灰色，解锁后点亮；孩子可写一句数学相关自我介绍。
14. 增加邀请分享追踪路径与影响力统计。
15. 分享授权统一改为“价值导向分享范围选择”，不使用冷冰冰授权勾选。

## 四、MVP 产品边界

### 4.1 MVP 必须跑通的四个闭环

#### 闭环一：孩子提问 → 审核 → 展示 → 热度 → 等待小讲师

最小路径：

1. 学习者登录；
2. 点击“我要提问”；
3. 上传题目图片 / 拍照原题；
4. 系统根据原题图片生成/建议问题标题与题目文字，家长辅助验证；选择年级、知识点下拉项、困惑描述下拉项，必要时填写“其他”；
5. 系统保存题目图片进入问题题库；
6. 系统显示温暖提示；
7. 老师后台审核；
8. 审核通过后进入你问我答列表；
9. 系统给孩子发送站内通知；
10. 其他孩子可点击“我也有这个困惑”为题目加热度；
11. 热度高的问题在可认领列表中适当靠前。

#### 闭环二：小讲师认领 → 72小时上传 → 审核 → 分享范围 → 发布/成长记录

最小路径：

1. 学习者点击“我要当小讲师”；
2. 进入可认领问题列表；
3. 选择题目；
4. 弹出小讲师认领贴士；
5. 确认后锁定题目，开始72小时倒计时；
6. 若无法继续，可点击“请假退出”，题目自动释放；
7. 上传讲解视频；
8. 选择分享范围：
   - A. 只分享给出题人和加热度的同学；
   - B. 愿意分享到成果广场，启发和鼓舞更多同学；
9. 老师审核；
10. 审核通过后发送站内通知；
11. 若选择B，进入成果广场；若选择A，只给出题人/相关同学和本人可见；
12. 讲解推送给提问者和加热度同学；
13. 小讲师成长护照记录帮助人数。

#### 闭环三：项目解锁/报名 → 组队 → 协作空间 → 成果提交 → 审核/证书/反馈

最小路径：

1. 学习者进入项目营；
2. 查看项目卡片：知识点、能力观察方向、解锁条件、组队状态、有效时长；
3. 满足解锁条件或家长完成付费报名；
4. 进入等待组队状态；
5. 系统显示组队进度，如“第一组已加入2名，还缺1名即可组团”；
6. MVP阶段按报名顺序组队，后续可按能力观察记录组队；
7. 组队成功后系统开启协作台；
8. 小组进行任务卡、留言、过程上传、成果提交；
9. 提交成果时选择分享范围；
10. 老师审核；
11. 审核通过后生成结营证书，记录能力收获；
12. 项目完成后先保留轻量感受入口；当孩子完成/解锁5个项目，或完成一个付费主题项目包时，再弹出儿童视角反馈问卷；
13. 成果、证书、过程记录可永久回看。

#### 闭环四：成果展示 → 点赞鼓励 → 分享传播 → 影响力记录

最小路径：

1. 审核通过且选择公开分享的成果进入成果广场；
2. 其他孩子/家长可点赞鼓励；
3. 页面展示温暖行动号召，引导提问、当小讲师、参加项目；
4. 成果或成长护照可生成分享图；
5. 邀请链接可记录新同学注册与有效参与；
6. 成长护照记录“影响/激发了多少位小同学”。

## 五、页面原型结构 V2

### 5.1 首页原型

```text
[顶部导航]
电脑/平板：Logo 数学小讲师联盟 | 首页 | 你问我答 | 项目营 | 成果广场 | 个人中心
手机：Logo 数学小讲师联盟 | ☰ 折叠菜单

[首屏 Hero]
标题：数学小讲师联盟
Slogan：会思考，爱数学
副标题：小学低年级孩子的数学共学社区
标签：小学1–3年级 / 同伴互助 / 项目制学习 / 低焦虑成长
按钮：我要提问 | 看看孩子怎么学

[平台温暖数据 + 能力星云]
已提出 X 个好问题 / 已解答 X 个问题 / X 位孩子参与探索 / X 个小组完成协作
周围悬浮能力词：画图表达 / 认真倾听 / 合作探索 / 勇敢提问 / 讲清思路 / 发现规律

[孩子怎么学]
卡片1 提出真实问题：拍照上传原题，说出哪里想不明白
卡片2 认领一道我能讲的问题：成为小讲师，帮助同学
卡片3 参加一个数学小项目：和伙伴一起观察、测量、表达、提交成果
卡片4 留下自己的成长作品：成果、证书、助人记录进入成长护照

[适合谁 / 不太适合谁]
适合：愿意在真实问题里慢慢想、愿意把自己的想法说出来、愿意听伙伴解释、愿意用画图/测量/操作去理解数学的小学低年级孩子。
不太适合：只追求短期刷题提分、只想被动听标准答案、不能接受孩子表达还不完美、希望用排名刺激孩子学习的家庭。

[你问我答预览]
问题卡片 + 热度 + 已发布讲解预览
按钮：我要提问 / 我要当小讲师 / 进入你问我答

[项目营预览]
免费基础项目 + 付费进阶项目
项目卡展示：知识点 / 解锁条件 / 组队状态 / 有效时长

[精选成果预览]
小讲师视频 / 项目成果 / 点赞鼓励 / 生成分享图

[安全、审核与低焦虑承诺]
发布前审核 / 不做公开排名 / 孩子是真正主角 / 积分和能力细节私密
```

MVP功能要求：

- “我要提问”未登录时弹登录/注册弹窗，登录后返回提交问题流程；
- “看看孩子怎么学”锚点跳转到首页内部模块；
- 首页数据为平台级鼓舞数据，不做排行榜；
- 首页副标题和年级标签按阶段2 V2执行。

### 5.2 你问我答页面原型

```text
[页面标题]
你问我答：孩子提出问题，孩子尝试讲清楚
按钮：我要提问 | 我要当小讲师

[温暖数据条]
已有 X 个问题被提出 / X 个问题被解答 / X 位同学被帮助

[筛选区]
年级 / 知识点 / 状态：待认领、已认领、已讲解 / 热度排序

[问题列表]
问题卡片：
- 问题标题
- 原题图片缩略图
- 年级 / 知识点
- 困惑简述
- 状态
- 热度：X 位同学也有这个困惑
- 提问者昵称 + 提问者身份星级
- 按钮：查看详情 / 我也有这个困惑 / 我来讲

[已发布讲解]
视频卡片：
- 讲解标题
- 小讲师昵称 + 星级
- 帮助人数：帮助了 X 位同学
- 审核通过标记
- 分享范围标记：公开 / 仅相关同学可见
- 查看讲解
```

#### 热度按钮说明弹框

点击“我也有这个困惑”前，弹出轻说明：

```text
如果你也有相同的困惑，请为这道题增加热度。
热度不是比赛，也不是排名；它只是告诉小讲师：这道题有更多同学想弄明白。
当有小讲师发布讲解后，你也会收到提醒。
```

MVP规则：同一学习者对同一道题只能加热度一次；热度数可影响可认领列表排序，但不显示排行榜。

#### 提交问题页面

字段与组件：

- 上传图片 / 拍照原题按钮；
- 拍照提示：请尽量拍清楚完整题目；
- 问题标题：不要求孩子自己概括。MVP可由系统根据题目文字生成“建议标题”，或由家长辅助填写/验证，例如“这道面积题我不会想”；
- 题目文字版：OCR识别后由家长确认；若MVP OCR未完成，则可由家长选填/老师后台补录；
- 年级；
- 知识点下拉选择：数与运算 / 图形与空间 / 测量 / 时间与人民币 / 找规律 / 应用题 / 其他（可编辑）；
- 困惑描述下拉选择：看不懂题意 / 不知道先算什么 / 画图不会画 / 算式会错 / 有两种想法不确定 / 想听听别人的方法 / 其他（可编辑）；
- 提交按钮。

系统处理：

- 保存原题图片进入问题题库；
- MVP可先人工/半自动标注；
- OCR/AI识别题目文字、知识点、题型作为后续增强；MVP阶段可先用家长验证 + 老师审核补标；
- 提交后显示温暖提示；
- 审核通过后发送站内通知。

#### 我要当小讲师流程

1. 点击“我要当小讲师”；
2. 进入可认领问题列表；
3. 点击“我来讲”；
4. 弹出小讲师认领贴士；
5. 确认后锁定题目；
6. 72小时倒计时；
7. 上传视频或点击请假退出；
8. 选择分享范围；
9. 提交审核；
10. 审核通过后通知孩子，并推送给提问者和加热度同学。

#### 分享范围选择

```text
你希望这段讲解帮助谁？

A. 只分享给出题人和加热度的同学，帮助真正关心这道题的人。
B. 愿意分享到成果广场，启发和鼓舞更多同学。
```

### 5.3 项目营页面原型

```text
[页面标题]
项目营：用数学完成真实小任务

[项目数据条]
已有 X 位孩子参与 / X 个项目小组完成协作 / X 个项目成果被展示

[免费/付费权益对比]
免费基础项目：高质量、低门槛、适合自主组队完成，老师审核但不默认点评
付费进阶项目：更复杂主题、老师指导、节点跟进、展示与个性化反馈

[免费基础项目区]
项目卡片：
- 项目名称
- 适合年级
- 核心知识点
- 能力观察方向
- 解锁条件：如20积分/30积分/完成1个基础项目
- 组队状态：第一组已加入2名，还缺1名
- 有效时长：解锁后1个月内完成
- 当前状态：可报名 / 组队中 / 进行中 / 已结束
- 已参与人数 / 已完成小组数
- 按钮：查看介绍 / 解锁参加

[进阶项目包 / 主题项目营区]
MVP提供两个付费选择：
- 5个小项目组成的主题项目包：适合短周期体验，如“测量与空间小探险”。
- 20个小项目组成的长期探索计划：适合持续共学，如“低年级数学表达力成长计划”。

项目卡片：
- 项目主题
- 项目包类型：5项主题包 / 20项长期计划
- 项目周期或预计有效期
- 前置条件：积分/免费项目完成记录
- 付费报名入口
- 服务内容：老师指导、节点提醒、展示、个性化贡献反馈
- 组队状态

[项目成果预览]
精选项目成果卡片 + 点赞鼓励 + 查看详情
```

#### 付费项目报名弹窗

```text
[付费项目说明]
项目名称 / 项目包类型 / 适合对象 / 预计周期 / 解锁有效期 / 包含权益 / 退出与延期规则

[报名信息确认]
孩子昵称 / 年级 / 家长联系方式 / 想报名项目

[联系与付款]
老师微信二维码或报名老师联系方式
说明：老师/管理员确认后开通项目权限
```

MVP原则：

- 不只弹付款码；
- 先收集报名意向和家长联系方式；
- 老师/管理员第一时间获得信息；
- 付款后管理员手动开通项目权限；
- 自动支付解锁后置。

### 5.4 项目详情页原型

未登录可见：

- 项目介绍；
- 样例成果；
- 适合谁；
- 需要准备什么；
- 免费/付费权益说明；
- 登录/报名按钮。

登录后可见：

- 报名状态；
- 解锁条件；
- 已有积分/已完成前置项目；
- 组队状态；
- 有效时长；
- 认领/报名入口。

参与 / 解锁后可见：

- 协作空间入口；
- 小组成员；
- 过程记录；
- 成果提交；
- 节点提醒；
- 请假退出按钮。

#### 项目认领贴士

> 这是一次真实的数学小项目。认领后，请尽量认真参与；如果有特殊情况，可以请家长帮忙说明。正常请假退出不会被责备；无故退出累计3次后，将暂停一段时间的免费项目认领资格。完成项目后，你可以获得结营证书，并记录到成长护照。

#### 请假退出规则

- 免费项目：请假退出释放名额；正常请假不计入无故退出；无故退出累计3次暂停体验。
- 付费项目：报名前必须展示退出规则。项目开始前可取消、延期或转入下一期；项目开始后，原则上不支持无理由退费，因为退出会影响同组伙伴的协作完整性。若遇到生病、家庭突发情况等特殊原因，可由家长申请人工处理：优先延期、转入下一期、保留名额或按已使用服务比例部分处理。无故退出或长期不参与不退费，并记录为异常退出。MVP阶段所有退费/延期/保留名额均由管理员手工登记。

## 九、温暖提示语文案库 V2

### 9.1 文案标准

沿用阶段3 V0标准：温暖提示语不是简单夸孩子，而是网站教育气质的一部分。以《教育的目的》理念为基底：让孩子在真实经验中产生兴趣、形成理解、学会运用，并在表达、探索和合作中感到知识是活的。

全站文字要遵循三条原则：

1. 不制造焦虑：不说“领先别人”“不能落后”“冲榜”。
2. 不廉价夸奖：少说“你真棒”，多说“你把想法说出来了”“你愿意让别人看见你的思考”。
3. 让知识有生命：把数学写成观察、解释、合作、表达，而不是只写成刷题和答案。

### 9.2 新增场景文案

#### 审核通过通知

- “你的问题已经通过审核啦，正在等待小讲师来帮助你。”
- “你的讲解已经通过审核，可以帮助更多同学啦。”
- “你们小组的项目成果已经通过审核，已经记录到成长护照里。”

#### 热度场景

- “原来不止你一个人有这个困惑。谢谢你把问题说出来，帮助大家一起看见它。”
- “已经有 X 位同学也想弄明白这个问题，等待一位小讲师来点亮思路。”

#### 请假退出场景

- “谢谢你认真说明情况。题目会重新开放给其他小讲师，你以后还可以继续尝试。”
- “项目先暂停也没关系，重要的是诚实说明和认真对待。”

#### 点赞鼓励场景

- “你的鼓励已经送到啦，也许这会让小创作者更有勇气继续表达。”

#### 邀请影响力场景

- “你的分享让更多同学看见了数学可以这样学。”
- “你已经影响了 X 位小同学加入数学小讲师联盟。”
