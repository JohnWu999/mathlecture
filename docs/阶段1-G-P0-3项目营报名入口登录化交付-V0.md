## 1. 本轮目标

阶段1-G 的核心原则是：

> 公开内容低门槛浏览；真实互动必须登录注册并绑定身份。

P0-3 聚焦项目营详情页：

- 项目介绍、适合年级、学习目标、体验说明继续公开可浏览；
- 报名、加入项目、查看项目权益、提交项目成果等真实动作必须登录；
- 未登录态不再展示完整报名表单；
- 登录原因要讲清楚：项目权益、作品提交、老师反馈和成长记录都需要绑定到孩子账号，便于运营追踪。

## 2. TDD 红灯

新增规则测试：

```text
tests/stage1g-p03-project-registration-login-rules.test.mjs
```

覆盖三类边界：

1. `/projects/[id]` 必须读取 NextAuth 登录状态，把公开浏览和报名互动分层；
2. 未登录态必须出现：
   - “公开浏览不需要登录”
   - “报名和加入项目需要登录”
   - “登录后报名”
   - “登录后查看项目权益”
   - “登录后提交项目成果”
   - 带项目详情 callbackUrl 的登录入口；
3. 后端 `/api/projects/[id]/register` 必须继续使用 session，匿名写入 401，并将报名记录绑定到 `session.user.id`。

红灯验证结果：旧代码运行 P0-3 规则测试时 3 个子测试中 2 个失败，主要失败点为：

- `/projects/[id]` 只读取 `session`，没有读取 `status` 做公开浏览/互动登录分层；
- 未登录态仍存在完整报名表单，提交时才跳登录或提示；
- 页面缺少“登录后报名/权益/成果”三类真实互动登录说明。

## 3. 代码变更

### 3.1 项目详情页 `/projects/[id]`

文件：

```text
app/projects/[id]/page.tsx
```

完成变更：

- `useSession()` 改为读取 `{ data: session, status }`；
- 新增 `isLoggedIn` 与项目详情登录回跳：

```text
/math-young-lecturer/login?callbackUrl=/math-young-lecturer/projects/${id}
```

- 未登录态展示登录说明卡片，不展示完整报名表单；
- 卡片文案明确：
  - “公开浏览不需要登录”；
  - “报名和加入项目需要登录”；
  - 登录后报名、查看项目权益、提交项目成果都会绑定孩子账号；
  - 老师才能确认名额、跟进小组进度、推送反馈，并把项目过程写入成长记录。
- 未登录态 CTA 改为：
  - “登录后报名”；
  - “登录后查看项目权益”；
  - “登录后提交项目成果”。
- 登录态保留原完整报名表单：孩子昵称、年级、报名意向、联系方式、备注、提交按钮。
- 401 分支不再静默跳转，改为页面内状态提示“登录状态已过期，请重新登录后继续报名”。

### 3.2 报名 API 边界

文件：

```text
app/api/projects/[id]/register/route.ts
```

本轮未改变后端逻辑，但纳入 P0-3 规则测试确认：

- 使用 `getServerSession(authOptions)`；
- 未登录返回 401；
- 报名记录写入 `userId: session.user.id`，确保报名意向绑定账号。
