## 二、阶段2最终产品结构

### 2.1 主导航

主导航最终保留 5 个入口：

1. 首页；
2. 你问我答；
3. 项目营；
4. 成果广场；
5. 个人中心。

不进入主导航的内容：

- 登录 / 注册；
- 上传问题；
- 上传讲解；
- 问题详情；
- 项目任务书；
- 项目协作空间；
- 老师工作台；
- 管理后台。

这些功能作为场景内按钮、弹窗、子页面或登录后的角色后台存在。

### 2.2 账号与角色

最终采用三类账号：

1. **学习者账号**  
   即孩子账号，孩子是主体，家长只辅助上传、授权、支付、确认等操作。

2. **老师账号**  
   通过“个人中心”进入老师工作台，负责审核、能力标签、退回原因、项目节点查看等。

3. **管理员账号**  
   通过“个人中心”进入管理后台，负责用户、项目、权限、内容和数据管理。

个人中心是统一入口，根据登录身份分流。

## 三、首页最终结构

### 3.1 首页任务

首页不是完整说明书，而是让第一次进入的家长和孩子在约 30 秒内理解：

1. 这是什么；
2. 适不适合我家孩子；
3. 孩子在这里怎么学；
4. 和刷题、补课、AI答疑有什么不同；
5. 有没有真实成果可以看；
6. 如何开始。

### 3.2 首页模块

首页最终采用 7 个模块：

1. 首屏定位区；
2. 孩子怎么学；
3. 适合谁 / 不太适合谁；
4. 你问我答预览；
5. 项目营预览；
6. 精选成果预览；
7. 安全、审核与低焦虑承诺。

### 3.3 首屏定位

- 产品名：数学小讲师联盟；
- Slogan：会思考，爱数学；
- 副标题：小学低年级孩子的数学小讲师共学社区；
- 标签：小学1–2年级｜同伴互助｜项目制学习｜低焦虑成长。

### 3.4 首页首屏按钮

最终保留两个按钮：

| 按钮 | 指向 | 说明 |
|---|---|---|
| 我要提问 | 你问我答中的提交问题流程 | 行动入口，未登录时弹登录/注册 |
| 看看孩子怎么学 | 首页内部“孩子怎么学”模块 | 理解入口，不新开复杂页面 |

“我要讲题”不放在首页首屏，避免新用户尚未理解问答机制时产生困惑。小讲师入口放在你问我答场景中表达为“我要当小讲师”或“去认领一道题”。

### 3.5 首页公开数据

首页可展示平台级温暖数据，例如：

- 已有多少个好问题被提出；
- 已有多少个问题被小讲师解答；
- 已有多少位孩子参与项目探索；
- 已有多少个小组完成协作。

边界：展示鼓舞型群体数据，不展示个人排名和积分。

## 四、你问我答页面最终结构

### 4.1 页面任务

你问我答承担：

1. 展示已审核问题；
2. 让孩子提交真实问题；
3. 让孩子自主认领可讲的问题；
4. 展示已发布讲解；
5. 形成提问者和小讲师的成长记录。

### 4.2 页面模块

1. 页面标题与说明；
2. 操作入口区；
3. 问题列表；
4. 已发布讲解列表；
5. 问题详情子页面；
6. 提交问题流程；
7. 认领问题与上传讲解流程。

### 4.3 顶部操作入口

| 按钮 | 实际进入 | 说明 |
|---|---|---|
| 我要提问 | 提交问题流程 | 提交后进入审核 |
| 我要当小讲师 | 可认领问题列表 | 不是直接上传视频，而是先选题再讲 |

### 4.4 问题卡片信息

每张问题卡片展示：

- 问题标题；
- 年级 / 主题标签；
- 问题简述；
- 状态：待认领 / 已认领 / 已讲解；
- 提问者昵称与主身份轻展示；
- 按钮：查看详情 / 我来讲。

### 4.5 提交问题流程

1. 登录检查；
2. 填写问题标题；
3. 上传题目图片或输入文字；
4. 选择年级 / 主题；
5. 补充“我哪里想不明白”；
6. 提交审核；
7. 显示温暖提示语；
8. 审核通过后进入你问我答。

温暖提示示例：

> 感谢你的好问题，让我们的数学更有趣。

### 4.6 我要当小讲师流程

1. 进入可认领问题列表；
2. 选择一道问题；
3. 弹出“小讲师认领贴士”；
4. 孩子确认后系统自动锁定；
5. 48小时内上传讲解视频；
6. 超过48小时未上传，题目自动释放；
7. 老师审核数学正确性、表达清晰度、内容安全；
8. 审核通过后发布或进入个人成长记录；
9. 显示温暖提示语。

### 4.7 小讲师认领贴士

认领前以“小约定”形式展示：

- 认领后请在48小时内上传讲解视频；
- 48小时内未上传，题目会自动释放；
- 遇到特殊情况，可以请家长协助说明；
- 无故放弃累计3次后，暂停一段时间的认领资格；
- 讲解视频要尽量清楚：能看到题目、能听清声音、能讲出思考过程；
- 不要求一次讲得完美，重点是愿意思考、愿意表达、愿意帮助别人。

### 4.8 视频公开分享授权

孩子上传讲解视频时，提交页增加：

> □ 我愿意将这个讲解公开分享到成果广场。  
> 说明：公开前仍需要家长确认和老师审核。

未授权时，视频只进入个人成长记录和必要的提问反馈，不进入公开成果广场。

## 五、项目营页面最终结构

### 5.1 页面任务

项目营承担：

1. 展示基础项目和进阶项目；
2. 让孩子参与真实数学项目；
3. 形成探索家身份和项目成果；
4. 承接主要付费业务。

### 5.2 页面模块

1. 项目营介绍区；
2. 免费基础项目区；
3. 进阶项目 / 主题项目营区；
4. 项目成果预览；
5. 项目参与规则说明；
6. 项目详情 / 任务书 / 协作空间子页面。

### 5.3 项目卡片信息

每个项目卡片展示：

- 项目名称；
- 适合年级；
- 项目主题；
- 核心知识点标签，例如面积、周长、测量、图形分割、统计、规律；
- 能力标签，例如画图表达、动手制作、小组合作、观察记录、讲清楚思路；
- 预计周期；
- 当前状态：可报名 / 进行中 / 已结束；
- 已参与人数 / 已完成小组数等项目级数据；
- 按钮：查看介绍 / 报名参加。

标签展示原则：每张卡片最多展示2–4个核心标签，帮助孩子判断方向，不把卡片变成成人化说明书。

### 5.4 免费项目与付费项目边界

#### 免费基础项目

- P0 建议开放1–3个免费基础项目，成熟后扩展到1–5个；
- 采用异步轻协作；
- 以自主体验、系统节奏、过程上传、自动结营证书为主；
- 老师不默认组织线上视频会，不默认提供长篇个性化点评。

#### 付费进阶项目 / 主题项目营

- 可包含同步启动、破冰、中期展示、结营展示；
- 可包含老师节点提醒和个性化贡献反馈；
- 可承接主要付费业务，用项目收入反哺免费社区审核成本。

### 5.5 项目详情页可见边界

未登录可见：

- 项目介绍；
- 样例成果；
- 适合谁；
- 需要准备什么。

登录后可见：

- 报名状态；
- 是否已解锁；
- 任务节奏；
- 提交入口。

参与 / 解锁后可见：

- 正式任务书；
- 协作空间；
- 小组成员；
- 过程记录；
- 成果提交；
- 节点提醒。

### 5.6 项目认领 / 报名前的小约定

点击报名或认领项目前，弹出认领贴士：

- 认领项目后，请认真参与，不要随意退出；
- 如果确实有特殊情况，可以请家长帮忙说明；
- 无故退出累计3次后，将暂停一段时间的免费项目认领资格；
- 完成项目后，可以获得项目结营证书，并记录到成长护照；
- 免费项目主要鼓励自主体验；付费项目会有老师指导、节点提醒和个性化反馈。

按钮：

- 我知道了，开始认领；
- 我再想想。

### 5.7 协作空间最终结构

MVP阶段采用结构化协作空间，而不是复杂在线协作文档。

协作空间包含：

1. 老师公告区：项目目标、本周任务、注意事项；
2. 任务卡片区：谁负责观察、画图、讲解、整理等；
3. 小组留言 / 聊天区：支持文字、图片，必要时家长辅助输入；
4. 作品上传区：草稿、图片、视频、文档；
5. 项目进度区：已加入、已分工、已提交草稿、已完成作品、老师已点评、已结营；
6. 成果墙；
7. 自动结营证书。

所有核心交流、提交、点评、节点记录都应能在后台留痕和存档。AI智能分析作为后续增强。

### 5.8 项目成果公开分享授权

项目成果提交页增加：

> □ 我愿意将这个项目成果公开分享到成果广场。  
> 说明：公开前仍需要家长确认和老师审核。

## 六、成果广场最终结构

### 6.1 页面任务

成果广场是独立展示舞台，承担：

1. 展示已审核、已授权、无隐私风险的孩子成果；
2. 给家长建立信任；
3. 给孩子留下作品被看见的舞台；
4. 鼓舞更多孩子参与；
5. 但不做排名、不做积分比较。

### 6.2 页面模块

1. 页面标题与说明；
2. 筛选区；
3. 小讲师视频成果；
4. 项目成果；
5. 孩子身份卡片弹窗；
6. 平台级 / 项目级数据展示；
7. 成果分享入口；
8. 进入相关页面的入口。

### 6.3 成果卡片信息

每张成果卡片展示：

- 成果标题；
- 成果类型：讲解视频 / 项目成果；
- 孩子昵称；
- 当前相关主身份和星级，例如：小语｜探索家 ★★；
- 简短成果说明；
- 审核 / 授权标记；
- 查看详情按钮；
- 分享按钮 / 生成分享图入口。

### 6.4 公开数据展示

可展示鼓舞型数据：

- 已有多少个问题被解答；
- 已有多少个项目成果被展示；
- 已有多少位孩子参与过协作；
- 某个项目已有多少人参与、多少个小组完成。

边界：展示平台级、项目级、群体级数据，不展示个人排名，不写“超过了多少人”。

### 6.5 分享功能

成果详情页支持生成适合保存和转发的分享图：

- 视频讲解成果卡；
- 项目成果卡；
- 结营证书图；
- 成长护照阶段摘要图；
- 年度感谢长图。

分享图只包含已授权公开的信息：孩子昵称、头像或系统头像、作品标题、主身份星级、简短感谢或鼓励语、平台标识。

移动端支持长按保存图片；桌面端支持下载图片。

### 6.6 不展示内容

成果广场不展示：

- 具体积分；
- 排名；
- 未授权个人信息；
- 细颗粒能力徽章；
- 老师后台标签；
- 未审核内容。

## 七、个人中心最终结构

### 7.1 入口规则

个人中心是统一入口，但登录后按角色分流：

- 未登录：弹出登录 / 注册；
- 学习者账号：进入孩子个人中心；
- 老师账号：进入老师工作台；
- 管理员账号：进入管理后台。

### 7.2 学习者个人中心模块

1. 孩子资料卡；
2. 我的提问；
3. 我的讲解；
4. 我的项目；
5. 成长护照；
6. 我的积分流水；
7. 老师反馈；
8. 隐私与公开授权。

### 7.3 孩子资料卡

展示：

- 孩子昵称；
- 头像：MVP优先支持系统儿童头像选择；真实头像上传作为后续功能，需家长确认和后台审核；
- 年龄 / 年级；
- 城市，可选且需授权；
- 主身份：提问者 / 小讲师 / 探索家；
- 星级；
- 简短介绍。

### 7.4 成长护照

成长护照展示完整成长记录，包括：

- 三个主身份星级；
- 能力徽章；
- 提问记录；
- 讲解记录；
- 项目记录；
- 老师反馈；
- 证书记录；
- 助人记录：我帮助了多少位同学、讲解了多少个问题；
- 合作记录：我和几位伙伴合作、完成了哪些项目；
- 阶段数据总结：提问数、讲解数、项目数、合作次数、获得感谢次数。

能力徽章和详细数据默认只在成长护照内展示，不在公开页面展示。

### 7.5 成长护照分享图

- “我的小讲师成长卡”；
- “我的项目探索记录”；
- “这一年，感谢你帮助了 X 位同学”；

分享前需要明确授权，默认隐藏真实姓名、学校、联系方式、具体积分和后台评价标签。

## 十一、温暖提示语与教育气质

### 11.1 建立标准

温暖提示语不是简单“夸孩子”，而是网站教育气质的一部分。文案建立以《教育的目的》的理念为基底：教育不是灌输惰性知识，而是让孩子在真实经验中产生兴趣、形成理解、学会运用，并在表达、探索和合作中感到知识是活的。

所有提示语应符合：

1. 真诚，不廉价表扬；
2. 站在儿童立场；
3. 有教育引导性；
4. 承认过程，而不只奖励结果；
5. 保护孩子的勇气；
6. 让知识变得有生命；
7. 不制造比较和焦虑。

### 11.2 文案公式

```text
看见孩子的动作 + 命名其中的学习价值 + 给出温暖的继续方向
```

示例：

> 你愿意把想不明白的地方说出来，这就是很棒的数学开始。也许你的问题，会帮另一个同学一起想明白。

### 11.3 场景示例

提问后：

- “感谢你的好问题，让我们的数学更有趣。”
- “你愿意把想不明白的地方说出来，这就是很棒的数学开始。”

小讲师上传后：

- “感谢你帮助了一个同学解惑。”
- “你把自己的思路讲出来，也让别人多了一种想法。”

项目提交后：

- “谢谢你和伙伴一起完成了一次真正的数学探索。”
- “你留下的不只是答案，还有观察、尝试和合作的过程。”

退回修改时：

- “这次还差一点点，我们一起把它改得更清楚。”
- “这不是失败，只是一次继续完善的机会。”

## 十二、阶段2保留、替换、降级与排除项

### 12.1 被保留并成为最终规则的内容

- 五个主导航：首页、你问我答、项目营、成果广场、个人中心；
- 登录/注册不作为主导航；
- 学习者账号就是孩子账号；
- 家长只辅助操作与授权；
- 主身份为提问者 / 小讲师 / 探索家；
- 主身份可公开轻展示，能力徽章与积分默认私密；
- 问答闭环和项目营均为P0；
- 付费核心放在进阶项目包/主题项目营；
- 成果公开必须审核与授权；
- 不公开排行榜、不公开积分。

### 12.2 被替换的内容

| 原讨论内容 | 最终替换为 |
|---|---|
| 登录/注册作为导航页 | 登录弹窗/受保护操作触发 |
| 家庭账号/家庭中心作为前台主体 | 学习者账号为孩子主体，家长辅助 |
| 成长中心 | 个人中心，按角色分流 |
| 问答广场 | 你问我答 |
| 我要讲题 | 我要当小讲师 |
| 项目官/项目探索者 | 探索家 |
| 公开能力徽章 | 能力徽章放入成长护照，默认私密 |
| 付费会员制/提问付费 | 付费核心放到进阶项目包/主题项目营 |

### 12.3 被降级为后续增强的内容

- 自动支付后解锁项目；
- AI自动分析协作过程；
- AI生成成长报告；
- 真实头像上传与审核；
- 复杂在线协作文档；
- 完整年度感谢长图模板；
- 更复杂的实时群聊或视频会议能力。

### 12.4 明确排除的方向

- 不做公开排行榜；
- 不公开积分总数；
- 不使用“超过多少人”等比较刺激文案；
- 不让AI替代孩子思考、讲解、项目表达；
- 不默认给免费提问/免费讲解提供长篇人工一对一点评；
- 不把老师工作台展示给普通学习者账号。
