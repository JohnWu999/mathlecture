## 1. 本次设计结论

已基于首页高保真 V1 的“灵动生命力版”和全站 UI 视觉方向“无限生长的数学森林”，生成三类分享海报高保真模板 V0。

三类模板分别是：

1. **我提出了一个好问题**：对应“问题发芽”，服务还处于提问阶段的孩子；
2. **我把这个方法讲清楚了**：对应“讲解长高”，服务小讲师讲解视频分享；
3. **我们一起完成了一个项目**：对应“项目成林”，服务项目成果分享。

三张海报视觉相连，但不共用同一个封面骨架，避免把讲题视频、项目成果、好问题混成一种模板。

---

## 2. 产品边界

- 只展示已审核、已授权公开的作品；未选择公开范围的内容不进入成果广场，也不生成公开分享海报。
- 不出现公开排名、积分总数、超过多少人、Top 等刺激比较文案。
- 二维码用于跳转作品/问题/项目详情；MVP 可先使用二维码占位，正式开发时由后端生成。
- 海报文案以孩子成长证据为核心，不夸张承诺、不成人化包装。

---

## 3. 三类模板说明

### 3.1 好问题海报｜问题发芽

核心文案：**我提出了一个好问题**  
视觉：新芽、问题气泡、暖黄便签、浅绿色生长底色。  
适用场景：孩子提交的问题通过审核后，可分享给家人、同学或成果广场。

设计目的：让“敢问”也被看见，照顾还没有开始讲题、只处于提问阶段的孩子。

### 3.2 小讲师讲解海报｜讲解长高

核心文案：**我把这个方法讲清楚了**  
视觉：强壮小树、黑板、年轮感、温柔提示“慢慢讲，我们听得见”。  
适用场景：小讲师讲解视频通过审核后，用于站内/站外分享。

设计目的：突出“讲清楚了什么”，不做“最棒讲师”式排名表达。

### 3.3 项目成果海报｜项目成林

核心文案：**我们一起完成了一个项目**  
视觉：森林、小组人物、测量标签、蓝绿项目底色。  
适用场景：小组项目成果通过审核并授权公开后，用于成果广场与外部分享。

设计目的：突出协作、真实探索和成果，不把小组项目包装成个人竞赛。

## 6. 视觉自检与微调记录

已使用 Playwright 导出整体预览与三张单独 PNG，并做视觉检查。根据检查结果已完成以下微调：

- 放大并加深三张海报右上角分类标签，提高手机缩略图场景下的识别度；
- 略微减弱二维码区域视觉重量，避免抢走标题和孩子作品信息；
- 保留三张模板“同一系列但不同骨架”的策略；
