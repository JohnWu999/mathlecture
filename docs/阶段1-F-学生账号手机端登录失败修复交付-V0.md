## 3. 根因判断

`app/login/page.tsx` 原逻辑：

```ts
const result = await signIn("credentials", { redirect: false, ... });
const session = await getSession();
const redirectPath = getPostLoginRedirectPath(session?.user?.role);
```

在手机浏览器 / 微信内置浏览器里，credentials 登录可能已经成功写入 cookie，但 `getSession()` 立即读取时 session 尚未刷新出来。此时 `session?.user?.role` 为空，前端会按未知角色决定跳转，用户看到的就是“学生账号登录不了 / 登录后没有进入个人中心”。

## 4. 代码修复

提交：`cd22739 stage1f: wait for student login session`

修改文件：

- `app/login/page.tsx`
  - 新增 `waitForPostLoginSession()`；
  - 登录成功后最多短暂重试 5 次读取 session，每次间隔 150ms；
  - 如果读到 role，则按 ADMIN / TEACHER / STUDENT 继续分流；
  - 如果登录成功但短时间仍读不到 role，则优先按学生入口完整加载 `/math-young-lecturer/profile`，避免留在登录页或走未知角色路径。

新增测试：
