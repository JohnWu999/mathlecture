# 阶段1-F｜个人中心入口故障修复交付 V0

时间：2026-06-09 06:06 CST

## 1. 用户反馈

犟爸在公网试用时反馈：

- 从网站导航栏点击【个人中心】，进入出错页面；
- 在【项目营】点击【查看我的成长护照】，也进入出错页面。

这两个入口最终都指向同一个业务落点：`/profile`（成长护照 / 个人中心）。

## 2. 本次定位结论

本次处理归入阶段1-F“入口真实性与业务闭环推进”。

已确认：

- 【项目营】里的【查看我的成长护照】按钮仍指向真实个人中心路由 `/profile`；线上渲染后 href 为 `/math-young-lecturer/profile`。
- 未登录访问 `/profile` 时页面外壳可打开，未登录接口 `/api/user/profile` 返回 401，符合权限边界。
- 个人中心登录后依赖 NextAuth session 与 `/api/user/profile` 返回的多类历史记录。旧实现存在两个入口韧性问题：
  1. 页面没有等待 NextAuth `status` 完成，就可能把 session 解析中的状态当作未登录/失败状态处理；
  2. 对历史讲题记录、项目报名记录默认假设关联题目/项目一定完整，历史数据如果存在残缺，就可能造成客户端渲染失败。

本次不把问题包装成“用户误操作”，而是按真实试运营入口故障处理：个人中心入口必须可进入、可反馈、可降级。

## 3. 已完成代码修复
