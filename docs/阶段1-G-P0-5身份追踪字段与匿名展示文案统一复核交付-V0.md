## 1. 本轮目标

统一阶段1-G中“匿名”的业务语义：

> 匿名不是匿名参与；匿名只表示公开展示时隐藏孩子姓名，后台仍记录账号，方便老师反馈和运营追踪。

本轮重点不是继续扩大登录门槛，而是把已经完成的登录边界进一步固化到数据展示层：

1. 提问写入继续绑定 `authorId = session.user.id`；
2. 公开问答列表和问题详情不再由前端自行用缺失姓名判断“匿名”；
3. API 统一返回 `publicAuthorDisplayName` 作为公开展示安全字段；
4. `/qa/ask` 匿名选项文案统一来自共享规则；
5. 继续保持 P0-1～P0-4 的登录边界与匿名写入 401。

## 2. 代码改动

### 2.1 新增统一规则文件

新增：

```text
lib/identity-display-rules.mjs
```

包含：

```text
PUBLIC_ANONYMOUS_DISPLAY_COPY
ANONYMOUS_QUESTION_AUTHOR_DISPLAY_NAME
DEFAULT_QUESTION_AUTHOR_DISPLAY_NAME
canSeePrivateQuestionAuthor()
getQuestionPublicAuthorDisplay()
maskQuestionAuthorForPublicDisplay()
```

统一文案为：

```text
公开展示时隐藏孩子姓名（后台仍会记录账号，方便老师反馈）
```

### 2.2 问题列表 API

修改：

```text
app/api/questions/route.ts
```

变化：

- `POST /api/questions` 仍要求登录；
- 新建问题仍写入：

```text
authorId: session.user.id
```

- `GET /api/questions` 公开列表增加展示安全字段：

```text
publicAuthorDisplayName
```

- 匿名展示时，公开侧使用“匿名小朋友”；但后台 `authorId` 仍保留为真实追踪字段。

### 2.3 问题详情 API

修改：

```text
app/api/questions/[id]/route.ts
```

变化：

- 保留：

```text
const isOwner = session?.user?.id === question.authorId
```

- 继续用 `authorId` 判断题主身份；
- 增加 `canSeePrivateAuthor` 判断：题主本人、老师、管理员可看私有作者身份；公开浏览者按匿名展示规则看到 `publicAuthorDisplayName`。

### 2.4 前端页面

修改：

```text
app/qa/ask/page.tsx
app/qa/page.tsx
app/qa/question/[id]/page.tsx
```

变化：

- `/qa/ask` 使用共享匿名展示文案；
- `/qa` 问题卡片不再用 `q.author.name || "匿名小朋友"` 判断匿名，而是渲染 API 返回的 `q.publicAuthorDisplayName`；
- `/qa/question/[id]` 问题详情不再内联判断 `question.isAnonymous ? "匿名小朋友" : ...`，而是渲染 `question.publicAuthorDisplayName`。
