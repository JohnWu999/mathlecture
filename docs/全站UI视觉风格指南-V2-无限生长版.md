# 全站 UI 视觉风格指南 V2｜无限生长版

项目：数学小讲师联盟  
当前阶段：阶段3补充交付｜视觉系统重构  
版本：V2｜无限生长版  
状态：用于替代 V1 的“温暖纸面感”基础方向，作为后续高保真 UI、首页视觉、组件系统、封面/海报模板的推荐方向  
更新时间：2026-05-29 14:20 CST

---

## 0. 本次为什么重构

V1 的问题不是“不好看”，而是**太安全、太常见、太像教育类网站模板**。它能表达温暖、可信、儿童友好，但缺少打开首页第一秒的记忆点。

数学小讲师联盟的内容内核很特别：

- 孩子先敢提出一个问题；
- 再尝试把自己的想法讲给别人；
- 最后和同伴一起完成项目；
- 从一棵小树苗，慢慢长成强壮的小树，再成为森林的一部分。

因此视觉系统不应只是“卡片 + 柔和颜色 + 插画”，而应把这个成长过程变成用户一眼能感受到的视觉世界。

本版推荐核心方向：

> **无限生长的数学森林**  
> 用“∞”作为隐形秩序，用“小树苗—大树—森林”表达孩子从提问、讲题到项目协作的蜕变。

---

## 1. 外部优秀教育网站参考与可吸收优点

本次参考了 Brilliant、Scratch、Outschool、Prodigy 等全球教育/儿童学习网站的首页视觉。不是复制它们，而是吸收它们能抓住用户第一眼的设计原则。

| 参考对象 | 可吸收优点 | 不直接采用的部分 |
|---|---|---|
| Brilliant | 首屏有清晰价值主张；把“学习过程”直接可视化，而不是只讲理念；产品演示卡让人马上知道怎么玩 | 不采用精英家教式表达，避免变成“专家教孩子” |
| Scratch | 色彩有记忆点；首屏像一个创作世界；孩子一看就知道“这里可以做东西” | 不采用过强儿童编程/游戏化视觉，避免偏离数学与家长信任 |
| Outschool | 大标题有情绪穿透力；真实孩子/有机形状/路径感让学习像一段旅程 | 不采用课程电商/兴趣班货架感 |
| Prodigy | 角色入口清晰；世界观强；孩子会觉得“我可以进去玩” | 不采用魔幻游戏闯关方向，避免强化积分刺激 |

综合结论：

1. **首页必须有一个可记忆的视觉隐喻**，不能只靠通用教育插画。  
2. **首屏要让用户看见学习过程**，而不是只读文案。  
3. **孩子要觉得“这里有我能进入的世界”**，父母要觉得“这里不是乱玩的游戏”。  
4. **视觉惊喜应来自产品理念本身**，而不是炫技、霓虹、过度动效。

## 2. 新视觉母题：无限生长的数学森林

### 2.1 Logo 与核心符号

用户已有 Logo 概念：

> 两个孩子握手，形成一个数学 ∞ 符号。

这个概念非常适合作为全站视觉基底。建议将 **∞** 从 logo 延展为全站的隐形秩序：

- 首页首屏：一条浅浅的 ∞ 生长路径贯穿画面；
- 卡片系统：卡片角落用半个 ∞ 曲线作为纹理；
- 成长路径：提问 → 讲题 → 项目，对应 ∞ 上的三个节点；
- 分享海报：用 ∞ 的一段作为孩子作品的边框；
- 加载动画：两颗点沿 ∞ 路径相遇，表达“问题找到讲解者”；
- 空状态：一颗种子在 ∞ 路径上等待发芽。

### 2.2 成长隐喻

本版把三个核心动作明确命名为：**问题发芽、讲解长高、项目成林**。

| 产品身份 | 视觉状态 | 教育含义 |
|---|---|---|
| 提问者 | 小树苗 / 种子 / 新芽 | 敢提出问题，就是思考开始生长 |
| 小讲师 | 强壮小树 / 主干 / 年轮 | 能讲给别人听，说明理解变得更清楚 |
| 探索家 | 森林 / 小组树冠 / 根系网络 | 能和同学合作，知识开始连接真实世界 |

### 2.3 视觉关键词

新的关键词不再是“温暖、干净、儿童友好”这种通用词，而是：

- **有生命的数学感**；
- **像进入一片会发光的思考森林**；
- **问题会发芽，讲解会长高，项目会成林**；
- **孩子是主角，老师是守林人，家长是看见成长的人**；
- **有惊喜，但不喧闹；有童心，但不幼稚；有数学，但不冰冷。**

## 3. 首屏体验原则：打开 3 秒内要发生什么

### 3.1 第一秒：看见一个不同于普通教育网站的世界

首屏不应只是左文案右插画。推荐结构：

```text
顶部导航
↓
大标题 + CTA
↓
横跨首屏的 ∞ 生长路径
↓
路径上有三个成长节点：
小树苗｜提问
小树｜讲题
森林｜项目
↓
右侧/中部浮出一张真实产品卡：今天有一个好问题正在等待讲解
```

用户第一眼应感受到：

> 这不是刷题站，也不是普通课程站。这里像一个孩子的数学成长世界。

### 3.2 第二秒：明白产品在做什么

首屏必须同时解释三件事：

1. 我可以提出问题；
2. 我可以讲给别人听；
3. 我可以和同伴做项目。

这三个动作最好不要用普通功能卡片，而是放在 ∞ 路径上，成为一条成长旅程。

### 3.3 第三秒：愿意往下滑

首屏底部设计一个“继续向下”的视觉钩子：

- ∞ 路径继续向下延伸；
- 一片叶子/数学符号从首屏飘到下一屏；
- 文案：“看看一个问题如何长成一片森林”；
- 下一屏承接“一个孩子的成长故事”。

## 4. 首页叙事结构建议

### 第一屏：数学森林入口

主标题建议：

> **让一个好问题，长成一片数学森林。**

备选：

- **会提问，会讲题，会和同伴一起探索。**
- **数学开窍，不是突然发生，是一次次说清楚、做出来。**
- **从一个问题开始，长出孩子自己的数学力量。**

主视觉：

- 背景是非常浅的米白/晨雾绿；
- 一个淡淡的 ∞ 曲线横跨首屏；
- ∞ 上有三段场景：小树苗、强壮小树、小森林；
- 两个孩子握手形成 ∞ 的 Logo 可以出现在左上或路径中心；
- 路径中有数学符号叶片：△、□、1/2、尺子、数轴点；
- 不要堆大量图标，核心是“一个连续成长世界”。

CTA：

- 主按钮：**我要提问**；
- 次按钮：**看看孩子怎么学**。

### 第二屏：一个问题的旅程

用故事而不是功能列表：

```text
我有一个问题
→ 有同学认领讲解
→ 老师审核，让讲解更准确
→ 更多孩子从这个问题里学到方法
→ 这个问题沉淀为成长记录
```

视觉：一张问题卡沿 ∞ 路径移动，旁边长出叶子/标注/小讲师头像。

### 第三屏：三种成长身份

不是普通三列卡片，而是三棵不同阶段的树：

- 提问者：新芽；
- 小讲师：树干；
- 探索家：森林。

每张卡上有一句价值文案：

- 提问者：**敢问，是数学思考发芽的第一步。**
- 小讲师：**讲清楚，是把自己的理解长成树干。**
- 探索家：**和同伴做出来，是让数学连接真实世界。**

### 第四屏：项目营像森林任务

项目卡不再只是课程卡，而是“森林任务卡”：

- 任务名；
- 所需人数；
- 需要的材料；
- 已有几位探索家；
- 解锁条件；
- 预计会长出什么成果。

### 第五屏：成果广场像森林展墙

成果展示不做瀑布流模板，而做“展墙 + 树枝分叉”：

- 小讲师视频封面：清爽、标题少、突出“我讲清楚了什么”；
- 项目成果封面：更像项目海报，突出“我们一起做出了什么”；
- 好问题海报：突出“我提出了一个好问题”。

## 5. 视觉系统规范

### 5.1 色彩系统

| 用途 | 色彩 | 建议值 | 说明 |
|---|---|---|---|
| 晨雾纸底 | Morning Paper | `#FFF8EA` | 替代普通白色，让页面有温度 |
| 森林主色 | Forest Ink | `#21483A` | 文字、主视觉、可信赖感 |
| 新芽绿 | Sprout Green | `#7EC85F` | 提问者/新手状态 |
| 讲解树绿 | Tree Green | `#2F8F67` | 小讲师/主按钮 |
| 无限蓝 | Infinity Blue | `#3B82F6` | 数学、连接、路径节点 |
| 阳光黄 | Sunlit Yellow | `#FFD166` | 惊喜、强调、徽章 |
| 果实橙 | Fruit Orange | `#F9733D` | 关键 CTA / 热度提示 |
| 土壤棕 | Soil Brown | `#8B6B4A` | 纸张阴影/手作质感 |
| 线稿灰绿 | Mist Line | `#D9E8D7` | ∞ 曲线、网格、分隔线 |

使用原则：

- 大面积用 Morning Paper + Forest Ink；
- ∞ 路径用浅灰绿或淡蓝，不喧宾夺主；
- CTA 用 Tree Green 或 Fruit Orange；
- 三种身份各自有色彩，但不做排名感。

### 5.2 字体与标题气质

推荐：

- 中文标题：圆润但有力量的黑体，如 `HarmonyOS Sans SC` / `Noto Sans SC`；
- 英文/数字：`Nunito` 或 `Inter`；
- 少量手写标注：可用仿手写风格，但只用于小标签，不用于正文。

标题应更有画面感：

- 不要：“高质量小学数学共学社区”；
- 推荐：“让一个好问题，长成一片数学森林”。

### 5.3 形状语言

| 元素 | 形状规则 |
|---|---|
| 主路径 | ∞ 曲线 / 分叉树枝 / 数轴路径 |
| 卡片 | 不完全规则的圆角矩形，像纸卡但更精致 |
| 标签 | 叶片形 / 种子形 / 小路标 |
| 按钮 | 圆角胶囊 + 轻微投影 |
| 成长节点 | 年轮圆点 / 发芽点 / 小树徽章 |
| 页面分区 | 像地形层：晨雾、草地、树冠、展墙 |

### 5.4 纹理与背景

可以使用：

- 极浅网格，表达数学；
- 手绘曲线，表达儿童思考；
- 年轮纹理，表达讲题后的理解沉淀；
- 叶片上的数学符号，表达知识有生命；
- ∞ 线条作为隐形布局参考。

避免：

- 大量卡通人物堆砌；
- 纯游戏地图；
- 霓虹渐变；
- 过强 3D 插画；
- 任何会让家长觉得“像游戏诱导”的视觉刺激。

## 6. 核心组件重构

### 6.1 GrowthPath｜无限成长路径

用于首页、个人中心、项目营。

结构：

```text
∞ 曲线背景
节点1：我提出了一个好问题
节点2：我讲清楚了一道题
节点3：我和同伴完成了一个项目
```

每个节点可显示：

- 状态：未点亮 / 已点亮 / 继续生长中；
- 对应身份：提问者 / 小讲师 / 探索家；
- 私密进度：只在个人中心展示；
- 公开展示：只显示已审核作品和身份星级。

### 6.2 QuestionSeedCard｜问题种子卡

用于你问我答、首页精选问题。

视觉：像一张埋着种子的卡片。

内容：

- 问题标题；
- 年级/知识点；
- “我卡住的地方”；
- 当前状态：等待讲解 / 已有小讲师认领 / 已长出讲解；
- 热度不做排名，用“有几个同学也想知道”。

### 6.3 LittleTeacherTreeCard｜小讲师树卡

用于推荐讲解、小讲师作品。

视觉：更稳、更高，有树干/年轮感。

内容：

- “我讲清楚了什么”；
- 讲解亮点；
- 老师审核印章；
- 表达能力标签；
- 不显示公开积分。

### 6.4 ForestProjectCard｜森林项目卡

用于项目营。

视觉：像一张森林任务牌。

内容：

- 项目名称；
- 所需人数，例如 3 人；
- 已加入人数；
- 解锁条件；
- 材料；
- 成果形式；
- 老师支持边界；
- 是否付费/项目包归属。

### 6.5 HarvestPoster｜成长收获海报

三类封面必须有差异：

| 类型 | 视觉重点 | 文案重点 |
|---|---|---|
| 好问题海报 | 小树苗 / 问号种子 | 我提出了一个好问题 |
| 小讲师视频封面 | 小树 / 讲解黑板 / 年轮 | 我把这个方法讲清楚了 |
| 项目成果封面 | 森林 / 小组 / 作品照片 | 我们一起完成了一个项目 |

## 7. 首页“惊喜感”落地细节

### 7.1 首屏微动效

MVP 可先用 CSS 动效，不增加复杂开发：

- ∞ 路径轻微呼吸；
- 数学叶片缓慢漂浮；
- 三个成长节点依次点亮；
- 鼠标经过节点时，弹出一句孩子视角文案；
- 页面向下滚动时，路径自然延伸到下一屏。

注意：

- 动效时间慢，不要像游戏抽奖；
- 支持 `prefers-reduced-motion`；
- 不影响阅读和性能。

### 7.2 第一屏文案

推荐主文案：

> **让一个好问题，长成一片数学森林。**

副文案：

> 在这里，孩子可以先提出问题，再尝试讲给别人听，最后和同伴一起做项目。数学不只是答对，更是把想法说清楚、做出来、连接起来。

CTA：

- 我要提问；
- 看看孩子怎么学。

### 7.3 首页视觉钩子

首屏底部加入一句：

> 往下看：一个问题如何发芽、长高、成林。

这会比普通“了解更多”更有叙事吸引力。

## 8. 后台与管理端如何保持统一

后台不能做成冷冰冰 SaaS，但也不能太童趣。

原则：

- 管理端保留森林色系，但降低插画和动效；
- 用“守林人工作台”作为隐性概念，但界面文字仍用专业名称：老师工作台、管理员后台；
- 审核状态可以用“待发芽/待修剪/可展示”这类内部小标签，但正式状态仍保持准确：待审核、需修改、已发布。

---

## 9. 风险与边界

| 风险 | 处理方式 |
|---|---|
| 过度童话化 | 控制人物数量，强调数学符号、真实作品和老师审核 |
| 过度游戏化 | 不做排行榜、抽奖、战力值；成长隐喻服务学习过程 |
| ∞ 符号滥用 | 只作为布局和路径母题，不每个角落都硬塞 |
| 树苗/森林太幼稚 | 用现代插画、精致线条、纸面纹理，不做低幼卡通 |
| 首屏太复杂 | 一屏只讲“问题→讲题→项目”三个节点 |

---

## 10. 推荐结论

我建议从 V1 的“温暖纸面感”升级为：

> **无限生长的数学森林**

这比普通教育网站更有记忆点，也更贴合数学小讲师联盟的内核：

- ∞ 表达孩子之间的连接与无限可能；
- 小树苗表达敢提问；
- 强壮小树表达能讲题；
- 森林表达项目协作与共同成长；
- 数学符号、网格、数轴、几何形状保证“数学感”；
- 纸面、作品展墙、老师印章保证“教育可信”。

下一步建议以这个方向进入高保真首页设计，重点先做：

1. 首页首屏；
2. 一个问题的成长旅程；
3. 三种身份成长卡；
4. 项目营森林任务卡；
5. 三类分享海报模板。
