## 1. 阶段1的判断

阶段1不是继续做视觉美化，而是处理犟爸指出的核心问题：

> 网站登录后，很多按钮看起来能点，但点击后不一定有真实业务动作；有些入口像正式功能，但没有写库、没有后台追踪、用户也看不到明确状态变化。

本阶段按“入口真实性”重新审计，并先补 P0 级真实闭环。判断标准不是“按钮能点”，而是：

1. 用户点击后是否有明确动作；
2. 是否真实写入数据库或受真实权限控制；
3. 后台/老师/管理员是否可追踪；
4. 用户是否能看到状态变化或清晰边界；
5. 做不到的是否不能伪装成已完成。

## 3. 本阶段 P0 修复清单

### 3.1 讲解审核闭环：修复“审核通过但前台不可见”的状态不一致

**问题**  
老师审核讲解时，只更新 `Answer.status`，但问题详情页展示逻辑需要 `reviewStatus = APPROVED`。这会造成：

- 老师端看起来已经审核；
- 前台孩子/用户侧可能看不到通过后的讲解；
- 这是典型“后台动作做了，但用户侧状态没闭合”。

**修复**  
`app/api/teacher/answers/[id]/review/route.ts`

- 通过时同时写：
  - `status: "APPROVED"`
  - `reviewStatus: "APPROVED"`
- 拒绝时同时写：
  - `status: "REJECTED"`
  - `reviewStatus: "REJECTED"`

**结果**  
老师审核动作与前台展示状态统一，形成更真实的“提交讲解 → 老师审核 → 前台可见/不可见”闭环。

---

### 3.2 老师待审核讲解队列：排除认领时自动生成的空占位

**问题**  
认领题目时可能生成空的 `Answer` 占位；老师待审核讲解队列如果只按 `status = PENDING` 查询，会把未真正提交视频的空记录也显示出来。

这会误导老师后台：看起来有待审核讲解，实际没有孩子提交的内容。

**修复**  
`app/api/teacher/answers/route.ts`

待审核讲解列表增加条件：

- `status: "PENDING"`
- `videoUrl: { not: "" }`

**结果**  
老师工作台只显示真实提交过讲解链接/视频地址的待审核内容。

---

### 3.3 项目协作空间：补上读取与写入权限保护

**问题**  
小组协作空间涉及孩子过程记录、作品提交、留言流。如果只要知道 group id 就能读取或写入，会造成：

- 非成员可以看到小组过程；
- 非参与者可以写入协作记录；
- 协作空间不能作为真实业务闭环评审对象。

**修复**  
`app/api/groups/[id]/messages/route.ts`

新增统一访问检查 `assertGroupAccess`，GET 和 POST 都必须通过：

- 已登录；
- 小组成员可以访问；
- 已获得该项目 `ACTIVE` 访问权的学习者可以访问；
- 老师/管理员可以访问，用于审核和运营；
- 其他用户返回 403：`无权访问这个小组协作空间`。

同时保留项目作品提交逻辑：如果协作记录内容符合项目作品提交规则，会创建 `ProjectArtifact` 草稿，进入后续老师审核与公开授权流程。

**结果**  
协作空间从“知道路径即可进入的半开放空间”，收紧为“成员 / 已开通项目 / 老师管理员可追踪”的真实协作入口。

---

### 3.4 咨询二维码上传：限制为管理员操作

**问题**  
上传接口已有真实文件写入能力，但运营二维码属于平台级资产。如果任意登录用户都能以 `consultation-qr` 类型上传，会造成内部评审时误判权限边界。

**修复**  
`app/api/uploads/route.ts`

新增规则：

- `kind === "consultation-qr"` 时，必须 `session.user.role === "ADMIN"`；
- 非管理员返回 403：`只有管理员可以上传咨询二维码`。

**结果**  
运营资产上传不再是任意登录用户可操作，后台运营入口边界更真实。

## 7. 下一步建议

建议进入阶段1后续批次：

### 阶段1-F：入口清单可视化

把所有前台和后台按钮列成表格：

- 页面；
- 按钮；
- 当前动作；
- 是否写库；
- 谁能看到状态；
- 后台是否可追踪；
- 分类：真实可用 / 半真实 / 开发中 / 需要隐藏。

### 阶段1-G：报名与开通闭环

重点核验：

- 项目报名是否形成管理员可跟进记录；
- 管理员是否能处理报名；
- 开通项目访问权后用户是否能进入对应协作空间；
- 用户侧是否能看到“已报名 / 待跟进 / 已开通 / 未开通”。

### 阶段1-H：上传与作品提交闭环

重点核验：

- 图片 / 视频上传是否真实落盘；
- 提交作品是否关联项目、小组、提交人；
- 老师审核后是否进入成果广场；
- 撤回授权后是否从成果广场移除但保留学习记录。

### 阶段1-I：假入口降级与文案标注

对暂时不能补齐的入口：

- 改成“开发中”；
- 改成“当前仅支持链接提交”；
- 改成弱按钮；
- 或隐藏，不让它伪装成已完成。
