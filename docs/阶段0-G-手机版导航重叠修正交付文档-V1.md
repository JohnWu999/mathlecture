# 阶段0-G｜手机版导航文字重叠修正交付文档 V1

时间：2026-06-08 22:17 CST  
线上地址：http://159.75.144.28/math-young-lecturer

## 1. 用户反馈

犟爸指出：

1. 网站导航栏依然不正常；
2. 手机版导航栏出现文字重叠；
3. Logo 图标可以缩小一些；
4. “数学小讲师联盟”应放在 Logo 图正下方。

## 2. 判断

反馈成立。

阶段0-F虽然把手机端分页标题改成了“你问我答｜项目营｜成果广场｜个人中心”，但仍放在同一条横向导航行里，与 Logo、菜单按钮共同抢占宽度。小屏设备上容易出现挤压和文字重叠。

## 3. 根因

`components/navbar.tsx` 中手机端布局仍是单行 flex：

- 左侧 Logo；
- 中间分页标题；
- 右侧菜单按钮；
- 品牌文字在手机端被隐藏。

这导致手机宽度不足时，中间分页标题没有独立行，容易和 Logo / 菜单区域发生挤压。

## 4. 本次修正

本次只修手机版导航，不改其他 UI 和业务逻辑。

### 4.1 手机端导航改为两行结构

在 `@media (max-width: 620px)` 下：

- `.nav-inner` 从单行 flex 改为两行 grid；
- 第一行：居中展示 Logo + “数学小讲师联盟”；
- 第二行：展示分页标题 `你问我答｜项目营｜成果广场｜个人中心`；
- 菜单按钮固定在右上角，不再参与正文排版挤压。

### 4.2 Logo 缩小

手机端 Logo 从原来的约 `36px × 28px` 调整为 `30px × 20px`。

### 4.3 品牌文字放在 Logo 正下方

手机端 `.forest-brand` 改为纵向排列：

- Logo 在上；
- “数学小讲师联盟”在正下方；
- 字号降低到 11px，避免挤占导航高度。

### 4.4 分页标题防重叠

分页标题行单独占满一整行，并允许极窄屏幕下横向滚动：

- `grid-column: 1 / -1`；
- `width: 100%`；
- `overflow-x: auto`；
- 保留“｜”分隔。
