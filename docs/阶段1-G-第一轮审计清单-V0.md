## 1. 审计结论摘要

第一轮审计结论：

1. **后端写入接口整体已经具备登录保护基础。**  
   匿名请求创建问题、提交讲解、认领、加热度、采纳、报名、上传均返回 401，未发现匿名写入成功。

2. **数据库模型已经具备身份追踪基础。**  
   `Question.authorId`、`Answer.lecturerId`、`ProjectRegistration.userId`、`ProjectArtifact.authorId`、`QuestionHeat.userId` 等关键字段均绑定 `User`。

3. **公开 GET 边界总体符合阶段1-G方向。**  
   `/api/questions?status=OPEN` 只返回审核通过问题，嵌套 answers 只返回双 APPROVED；`/api/projects` 继续沿用阶段1-F价格真实性规则；`/api/hall` 继续诚实空状态。

4. **前端页面仍存在阶段1-G要修的主要问题。**  
   `/qa/ask` 未登录可直接看到完整提问表单，只在提交时页面内报“请先登录”；这不符合“真实互动入口先明确登录门槛”的新产品口径。  
   `/projects/[id]` 未登录可看到完整报名表单，只在提交时报登录跳转；这也需要改为“公开介绍 + 登录后参与”。  
   `/qa` 的“我要提问”当前直接链接 `/qa/ask`，未登录态缺少登录说明。  
   `/qa/question/[id]` 已在交互动作中有登录跳转，但需要进一步统一未登录提示文案和按钮状态。

5. **公网受保护页面仍正常保护。**  
   `/profile`、`/teacher`、`/admin` 未登录 307 跳 `/login`；`/api/user/profile`、`/api/teacher/outcomes` 未登录 401。

因此，阶段1-G第一轮审计建议：

> 不需要推翻阶段1-F；下一步应优先修前端登录门槛表达，再补规则测试，最后统一 API 权限断言与文案。

## 5. 第一轮问题清单

### G-P0-1｜提问入口未登录仍展示完整表单

优先级：P0  
文件：`app/qa/ask/page.tsx`

问题：未登录用户可以看到完整提问表单，只在提交时显示“请先登录”。

建议：未登录态显示登录门槛说明卡片和“去登录/注册”按钮；登录后再展示表单。

验收：

- 未登录 `/qa/ask` 不展示可编辑提问表单。
- 未登录看到明确说明：登录是为了老师讲解完成后准确推送反馈。
- `POST /api/questions` 继续 401 保护。

### G-P0-2｜问答公开页互动入口文案不足

优先级：P0  
文件：`app/qa/page.tsx`、`app/qa/question/[id]/page.tsx`

问题：公开页可浏览是正确的，但“我要提问”“去认领一道题”等入口需要明确登录后参与；详情页未登录互动按钮也需统一说明。

建议：未登录态 CTA 改为“登录后提问 / 登录后参与讲解”，并保留公开浏览说明。

验收：

- `/qa` 未登录仍可浏览公开列表。
- 未登录点击提问/认领/热度等动作进入登录提示或登录页。
- 页面文案清楚解释不是限制浏览，而是为了反馈追踪。

### G-P0-3｜项目详情未登录仍展示完整报名表单

优先级：P0  
文件：`app/projects/[id]/page.tsx`

问题：未登录可以看到并填写完整报名表单，提交时才跳登录。

建议：未登录只展示项目介绍、适合年级、学习目标、体验说明和登录后参与提示；登录后再展示报名意向表单。

验收：

- 未登录 `/projects/[id]` 不展示完整报名表单。
- 未登录有“登录/注册后报名项目”入口。
- `POST /api/projects/[id]/register` 继续 401 保护。

### G-P0-4｜API权限需要固化为规则测试

优先级：P0  
文件建议：新增 `tests/stage1g-auth-boundary-rules.test.mjs`

问题：当前 API 多数已经保护，但阶段1-G需要把规则固化，防止以后回退。

建议测试覆盖：

- `app/api/questions/route.ts` 的 POST 必须 `getServerSession` 且未登录 401。
- `app/api/answers/route.ts` 的 POST 必须登录。
- `app/api/questions/[id]/claim/route.ts`、`heat/route.ts`、`answers/[id]/approve/route.ts` 必须登录。
- `app/api/projects/[id]/register/route.ts` 必须登录。
- `app/api/uploads/route.ts` 必须登录。
- 页面未登录态不能展示主要互动表单。

### G-P0-5｜匿名字段语义需重定义

优先级：P0.5  
文件：`app/qa/ask/page.tsx`、`lib/qa-ui-rules.mjs`、相关文档

问题：`isAnonymous` 容易被误解成“无需注册”。

建议：保留字段，但文案改成：

```text
公开展示时隐藏孩子姓名（后台仍会记录账号，方便老师反馈）
```

验收：用户理解“匿名展示”不等于“匿名参与”。
