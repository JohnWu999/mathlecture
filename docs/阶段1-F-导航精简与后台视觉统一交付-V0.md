# 阶段1-F｜导航精简与后台视觉统一交付 V0

时间：2026-06-09 08:03 CST

## 1. 用户反馈

犟爸反馈：

1. 登录按钮旁边单独设置【我要提问】按钮会造成导航栏重复；
2. 导航栏要保持简洁，需要删减重复功能入口；
3. 老师工作台和管理员后台页面 UI 视觉需要更新到最新版本，和全网站保持风格一致。

## 2. 判断

### 2.1 导航栏

【你问我答】已经是全站主导航入口，进入后可以继续完成提问流程；导航栏右侧再放一个独立【我要提问】按钮，会让顶部信息层级变复杂，尤其在手机端不利于保持简洁。

本轮处理：

- 删除桌面端登录区域旁边的独立【我要提问】按钮；
- 删除折叠菜单里的重复【我要提问】入口；
- 保留主导航【你问我答】，提问动作仍在你问我答业务流内完成；
- 保留登录 / 账户名 / 退出登录等账户动作。

### 2.2 老师 / 管理员后台

老师工作台和管理员后台原来使用旧的 `guardian-*` / `sticker-*` 表面类，和当前网站最新的 Morning Paper / Forest Ink / soft card 体系不一致。

本轮处理：

- 老师工作台改为 `forest-workspace-shell`、`forest-page-hero forest-workspace-hero`、`forest-dashboard-card`、`forest-panel`、`forest-card`、`forest-empty`；
- 管理员后台同步改为同一套 V2 forest workspace 视觉；
- 新增 `forest-workspace-*` CSS 组件别名，统一后台 hero、面板、指标卡、tabs；
- 保留后台“守林人工作台”的专业隐喻，但去掉旧 guardian/sticker 视觉依赖。
