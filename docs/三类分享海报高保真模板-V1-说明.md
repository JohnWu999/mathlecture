# 三类分享海报高保真模板 V1 说明

## 本轮反馈处理结论

| 反馈 | 判断 | V1 处理 |
|---|---|---|
| 海报文字密集，重点不够突出；可用字体、色号区分 | 采纳 | 减少卡片说明、缩短二维码提示；主标题拆成小标题 + 大关键词；三类强调色分别为绿色、橙色、蓝色。 |
| 小讲师视频海报背后的小树遮挡文字 | 采纳，并固化为规则 | 图案不得进入文字安全区；小讲师视频海报改为“黑板舞台 + 侧边小树”，树缩小并后退，不再压住主标题、说明或内容卡片。 |
| 三张海报同属一个系统，但区分度不够 | 采纳 | 统一保留品牌、成长森林、圆角卡片和口号；差异化为：问题发芽=问号泡泡+新芽，讲解长高=黑板舞台+播放符号，项目成林=横向森林+小组场景。 |

## V1 设计原则

1. **文字先行，图案让位**：所有装饰都只能服务氛围，不得遮挡或抢走主标题、内容卡片、二维码提示。
2. **三类海报不是换文案，而是换场景**：问题、讲解、项目分别对应不同视觉叙事。
3. **同系统感保留在底层**：统一品牌、圆角、暖色纸感、数学森林、口号“会思考，爱数学”。
4. **继续坚持低焦虑边界**：只展示已审核、已授权公开内容；不做排名，不公开积分。
