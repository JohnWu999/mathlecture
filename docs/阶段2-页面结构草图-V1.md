## 一、阶段2目标

阶段2不是写最终页面文案，也不是马上进入代码实现，而是先回答：

1. 每个主页面承担什么任务？
2. 每个页面上放哪些核心模块？
3. 哪些功能是页面内入口，哪些是弹窗或子页面？
4. 未登录、学习者账号、老师账号、管理员账号分别看到什么？
5. 首页按钮、导航入口、成果展示、个人中心如何相互连接？

阶段2完成后，才能进入：

- 页面原型；
- 交互细化；
- 组件拆分；
- MVP 代码重构。

## 二、全站主导航结构

主导航保留 5 个入口：

1. 首页
2. 你问我答
3. 项目营
4. 成果广场
5. 个人中心

不放入主导航：

- 登录 / 注册；
- 上传问题；
- 上传讲解；
- 问题详情；
- 项目任务书；
- 项目协作空间；
- 老师工作台；
- 管理后台。

这些功能不消失，而是作为：

- 场景内按钮；
- 子页面；
- 弹窗；
- 登录后角色后台。

## 三、首页结构草图

### 3.1 首页任务

首页不是完整说明书，而是让第一次进入的家长和孩子在 30 秒内判断：

1. 这是什么？
2. 适不适合我家孩子？
3. 孩子在这里怎么学？
4. 和刷题、补课、AI 答疑有什么不同？
5. 有没有真实成果可以看？
6. 如何开始？

### 3.2 首页模块顺序

建议首页采用 7 个模块：

1. 首屏定位区
2. 孩子怎么学
3. 适合谁 / 不太适合谁
4. 你问我答预览
5. 项目营预览
6. 精选成果预览
7. 安全、审核与低焦虑承诺

---

### 3.3 模块一：首屏定位区

#### 展示内容

- 产品名：数学小讲师联盟
- Slogan：会思考，爱数学
- 副标题：小学低年级孩子的数学小讲师共学社区
- 标签：小学 1–2 年级｜同伴互助｜项目制学习｜低焦虑成长

#### 首屏按钮

建议保留两个按钮：

1. **我要提问**
2. **看看孩子怎么学**

#### 按钮指向

| 按钮 | 指向 | 未登录处理 | 说明 |
|---|---|---|---|
| 我要提问 | 你问我答中的提交问题流程 | 弹出登录 / 注册 | 明确行动入口 |
| 看看孩子怎么学 | 首页内部“孩子怎么学”模块 | 不需要登录 | 理解型入口，不跳复杂页面 |

### 3.4 为什么首屏不直接放“我要讲题”？

因为新用户刚进入首页时，可能还不知道：

- 讲什么题？
- 是讲自己的题还是别人的题？
- 讲完谁看？
- 是否有老师审核？
- 孩子讲错怎么办？

所以首页首屏采用：

- 一个行动按钮：我要提问；
- 一个理解按钮：看看孩子怎么学。

“我要讲题 / 我要当小讲师”应该放在用户理解机制之后，出现在“你问我答”板块和“你问我答”页面中。

---

### 3.5 模块二：孩子怎么学

这是“看看孩子怎么学”按钮跳转的位置。

建议用 4 张流程卡片，不写成长文：

1. **提出真实问题**  
   孩子把自己想不明白的问题提交上来。

2. **认领一道我能讲的问题**  
   孩子选择一个自己能讲清楚的问题，成为小讲师。

3. **参加一个数学小项目**  
   和同伴一起完成测量、统计、图形、规律等探索任务。

4. **留下自己的成长作品**  
   通过审核的讲解和项目成果进入成长记录，也可能展示在成果广场。

#### 页面表现

- 用横向流程图或 2×2 卡片；
- 每张卡片配一个图标；
- 每张卡片只写一句解释；
- 不展示完整规则；
- 每张卡片下可放小入口：去提问 / 去认领 / 看项目 / 看成果。

---

### 3.6 模块三：适合谁 / 不太适合谁

采用双栏卡片。

#### 适合

- 小学 1–2 年级；
- 校内数学比较轻松；
- 愿意尝试表达、讲题、合作；
- 家长希望孩子发展思维、表达与协作能力。

#### 不太适合

- 主要目标是短期提分；
- 需要大量基础补差；
- 只希望老师单向讲、孩子被动听；
- 不能接受孩子表达中有不完美过程。

---

### 3.7 模块四：你问我答预览

#### 展示内容

- 3 个已审核问题卡片；
- 1–2 个已发布讲解预览；
- 简短说明：孩子提出问题，孩子认领讲解，老师发布前审核。

#### 按钮

- 我要提问；
- 去认领一道题；
- 进入你问我答。

#### 注意

“去认领一道题”可以引导小讲师行为，但放在这里比放在首页首屏更合适，因为用户已经理解了问答机制。

---

### 3.8 模块五：项目营预览

#### 展示内容

- 免费基础项目 1–3 个预览；
- 进阶项目 / 主题项目营样例；
- 项目成果小图；
- 项目营核心说明：不是刷题，而是用数学完成真实小任务。

#### 按钮

- 看看项目营；
- 查看可参加项目。

#### 权限

- 未登录：可看项目介绍和样例；
- 已登录学习者：可看免费项目和已解锁项目；
- 已报名 / 已解锁：可看任务书和协作空间。

---

### 3.9 模块六：精选成果预览

首页只展示少量精选成果，不承担完整成果展示功能。

#### 展示内容

- 2–4 个优秀小讲师视频；
- 2–4 个项目成果；
- 显示孩子昵称、主身份与星级，例如：小安｜小讲师 ★★；
- 不显示积分；
- 不做排名。

#### 按钮

- 进入成果广场。

---

### 3.10 模块七：安全、审核与低焦虑承诺

用 3 张承诺卡片：

1. **发布前审核**  
   问题、讲解和成果公开前经过必要审核。

2. **不做公开排名**  
   不公开积分，不做排行榜，不制造比较焦虑。

3. **孩子是真正主角**  
   孩子提问、讲解、探索；家长只是辅助操作。

---

## 四、你问我答页面结构草图

### 4.1 页面任务

你问我答是 P0 核心闭环之一，承担：

1. 展示已审核问题；
2. 让孩子提交问题；
3. 让孩子自主认领问题；
4. 展示已发布讲解；
5. 形成提问者和小讲师的成长记录。

### 4.2 页面模块

1. 页面标题与说明
2. 操作入口区
3. 问题列表
4. 已发布讲解列表
5. 问题详情子页面
6. 提交问题流程
7. 认领问题与上传讲解流程

### 4.3 顶部操作入口

建议有两个核心按钮：

1. 我要提问
2. 我要当小讲师

#### 按钮逻辑

| 按钮 | 实际进入 | 说明 |
|---|---|---|
| 我要提问 | 提交问题流程 | 提交后进入轻审核 |
| 我要当小讲师 | 可认领问题列表 | 不是直接上传视频，先选题再讲 |

### 4.4 问题卡片信息

每张问题卡片展示：

- 问题标题；
- 年级 / 主题标签；
- 问题简述；
- 状态：待认领 / 已认领 / 已讲解；
- 提问者昵称与主身份轻展示；
- 按钮：查看详情 / 我来讲。

### 4.5 问题详情子页面

展示：

- 问题完整内容；
- 图片或补充条件；
- 提问者授权展示信息；
- 已有讲解；
- 认领入口。

### 4.6 提交问题流程

步骤：

1. 登录检查；
2. 填写问题标题；
3. 上传题目图片或输入文字；
4. 选择年级 / 主题；
5. 补充“我哪里想不明白”；
6. 提交审核；
7. 审核通过后进入你问我答。

### 4.7 我要当小讲师流程

步骤：

1. 进入可认领问题列表；
2. 选择一道问题；
3. 系统自动锁定；
4. 上传讲解视频；
5. 老师审核数学正确性、表达清晰度、内容安全；
6. 审核通过后发布；
7. 进入孩子成长记录。

### 4.8 免费额度与限制

- 每个孩子每周 1–3 个问题提交审核机会；
- 小讲师同一时间最多认领 1 个问题；
- 讲解视频不作为主要付费点评业务；
- 老师免费流程主要负责审核与能力标签。

## 五、项目营页面结构草图

### 5.1 页面任务

项目营是 P0 的第二个核心闭环，承担：

1. 展示基础项目和进阶项目；
2. 让孩子参与数学项目；
3. 形成探索家身份和项目成果；
4. 承接主要付费业务。

### 5.2 页面模块

1. 项目营介绍区
2. 免费基础项目区
3. 进阶项目 / 主题项目营区
4. 项目成果预览
5. 项目参与规则说明
6. 项目详情 / 任务书 / 协作空间子页面

### 5.3 免费基础项目区

P0 建议开放 1–3 个免费基础项目，成熟后扩展到 1–5 个。

每个项目卡片展示：

- 项目名称；
- 适合年级；
- 项目主题；
- 预计周期；
- 当前状态：可报名 / 进行中 / 已结束；
- 按钮：查看介绍 / 报名参加。

### 5.4 进阶项目 / 主题项目营区

展示：

- 项目主题；
- 项目周期；
- 是否包含同步启动、破冰、中期展示、结营展示；
- 是否包含个性化贡献反馈；
- 解锁 / 报名入口。

### 5.5 项目详情页

未登录可见：

- 项目介绍；
- 样例成果；
- 适合谁；
- 需要准备什么。

登录后可见：

- 报名状态；
- 是否已解锁；
- 任务节奏；
- 提交入口。

参与 / 解锁后可见：

- 正式任务书；
- 协作空间；
- 小组成员；
- 过程记录；
- 成果提交；
- 节点提醒。

### 5.6 免费项目协作空间

免费项目不默认老师组织线上视频会，而采用异步轻协作：

- 任务卡；
- 系统节奏；
- 固定节点提醒；
- 小组留言 / 提交记录；
- 成果墙；
- 自动结营证书。

### 5.7 项目退出与机会冷却

- 正常请假 / 正常取消不惩罚；
- 无故退出 / 长期不提交计入项目参与记录；
- 累计 3 次后暂停新的免费体验项目机会；
- 不公开羞辱，不叫黑名单。

## 六、成果广场页面结构草图

### 6.1 页面任务

成果广场是独立展示舞台，承担：

1. 展示已审核、已授权、无隐私风险的孩子成果；
2. 给家长建立信任；
3. 给孩子留下作品被看见的舞台；
4. 但不做排名、不做积分比较。

### 6.2 页面模块

1. 页面标题与说明
2. 筛选区
3. 小讲师视频成果
4. 项目成果
5. 孩子身份卡片弹窗
6. 进入相关页面的入口

### 6.3 成果卡片信息

每张成果卡片展示：

- 成果标题；
- 成果类型：讲解视频 / 项目成果；
- 孩子昵称；
- 当前相关主身份和星级，例如：小语｜探索家 ★★；
- 简短成果说明；
- 审核 / 授权标记；
- 查看详情按钮。

### 6.4 不展示内容

成果广场不展示：

- 具体积分；
- 排名；
- 未授权个人信息；
- 细颗粒能力徽章；
- 老师后台标签；
- 未审核内容。

## 七、个人中心页面结构草图

### 7.1 页面任务

个人中心是统一入口，但登录后按角色分流。

入口逻辑：

- 未登录：弹出登录 / 注册；
- 学习者账号：进入孩子个人中心；
- 老师账号：进入老师个人中心 / 老师工作台；
- 管理员账号：进入管理后台。

---

### 7.2 学习者账号个人中心

学习者账号就是孩子账号。

建议模块：

1. 孩子资料卡
2. 我的提问
3. 我的讲解
4. 我的项目
5. 成长护照
6. 我的积分流水
7. 老师反馈
8. 隐私与公开授权

### 7.3 孩子资料卡

展示：

- 孩子昵称；
- 年龄 / 年级；
- 城市，可选且需授权；
- 主身份：提问者 / 小讲师 / 探索家；
- 星级；
- 简短介绍。

### 7.4 成长护照

成长护照展示完整成长记录，包括：

- 三个主身份星级；
- 能力徽章；
- 提问记录；
- 讲解记录；
- 项目记录；
- 老师反馈；
- 证书记录。

注意：能力徽章只在成长护照内展示，不在公开页面展示。

- 点击“我要当小讲师”；

## 十、老师审核工作台结构草图

### 10.1 入口

老师工作台不出现在普通学习者导航中。

老师账号点击“个人中心”后进入老师工作台。

### 10.2 模块

1. 待审核问题
2. 待审核讲解视频
3. 待审核项目成果
4. 能力标签勾选
5. 退回原因模板
6. 审核记录
7. 异常提醒
8. 项目管理入口

### 10.3 老师审核原则

免费流程中老师主要负责：

- 内容安全；
- 数学正确性；
- 表达是否基本清楚；
- 是否适合公开；
- 勾选能力标签；
- 必要时选择退回原因。

不默认提供：

- 长篇个性化点评；
- 一对一讲法指导；
- 多轮问题改写服务；
- 每个免费项目的详细人工总结。

## 十一、页面之间的连接关系

### 11.1 首页连接

首页 → 我要提问 → 登录弹窗 / 提交问题流程  
首页 → 看看孩子怎么学 → 首页内部学习路径模块  
首页 → 去认领一道题 → 你问我答可认领问题列表  
首页 → 看看项目营 → 项目营  
首页 → 进入成果广场 → 成果广场  
首页 → 个人中心 → 登录弹窗 / 角色分流

### 11.2 你问我答连接

你问我答 → 我要提问 → 提交问题流程  
你问我答 → 我要当小讲师 → 可认领问题列表  
问题卡片 → 问题详情  
问题详情 → 认领问题 → 上传讲解  
讲解审核通过 → 成果广场 / 个人中心成长记录

### 11.3 项目营连接

项目营 → 项目详情  
项目详情 → 报名 / 解锁  
报名成功 → 任务书  
任务书 → 协作空间  
协作空间 → 成果提交  
成果审核通过 → 成果广场 / 个人中心成长记录

### 11.4 成果广场连接

成果广场 → 成果详情  
成果卡片头像 → 孩子身份卡片  
成果详情 → 相关问题 / 相关项目  
成果详情 → 进入你问我答 / 项目营

个人中心 → 我的提问 → 问题详情

## 十二、阶段2待确认问题

为了进入页面原型，建议犟爸重点确认以下问题：

1. 首页首屏两个按钮是否最终定为：我要提问 / 看看孩子怎么学？
2. “看看孩子怎么学”是否确认跳到首页内部流程模块，而不是单独页面？
3. “我要讲题”是否改为在问答场景中表达为“我要当小讲师”或“去认领一道题”？
4. 成果广场卡片是否统一显示：孩子昵称 + 一个最相关主身份 + 星级？
5. 个人中心是否按本稿拆为：孩子资料卡、我的提问、我的讲解、我的项目、成长护照、积分流水、老师反馈、授权管理？
6. 老师工作台是否先只做审核、标签、退回原因和审核记录，不做复杂教务系统？
