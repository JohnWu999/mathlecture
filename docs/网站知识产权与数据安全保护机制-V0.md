# 网站知识产权与数据安全保护机制 V0

项目：数学小讲师联盟  
阶段：阶段3补充交付｜知识产权、反扒、数据安全  
版本：V0  
状态：作为后续开发实施计划中“安全与内容保护”模块依据

---

## 一、结论

网站需要设计知识产权保护机制，但不能把“反扒”理解成绝对防复制。任何公开网页内容，只要能被浏览器看到，就不能保证 100% 不被复制。

本产品应采用 **分层保护策略**：

1. **公开内容少而精**：成果广场只公开已审核、已授权、无隐私风险的内容；
2. **核心教学资产不直接裸露**：项目任务书、项目库、过程记录、原始视频、题目图片等需要登录、参与或后台权限；
3. **技术反扒降低批量抓取成本**：限流、签名链接、防盗链、图片水印、导出权限、审计日志；
4. **法律与版权声明兜底**：明确平台内容、项目设计、课程任务卡、孩子作品的使用边界；
5. **管理员掌握下载/导出权限**：老师只在授权范围内审核和查看，不默认拥有批量导出或下载原始素材权限。

## 二、内容分级保护

| 内容类型 | 是否公开 | 保护策略 |
|---|---|---|
| 首页文案、产品介绍 | 公开 | 可被搜索引擎索引；保留版权声明 |
| 成果广场作品 | 公开但需授权 | 只展示昵称、类型化封面、公开作品；不展示真实姓名/学校/联系方式/积分/后台标签 |
| 你问我答问题列表 | 半公开 | 只展示已审核问题；原图可压缩/加水印；敏感信息打码 |
| 题目原图 | 受控 | 默认只给相关用户、老师、管理员查看；公开展示时压缩和水印 |
| 小讲师原始视频 | 受控 | 公开版可播放；原始文件下载仅管理员；视频 URL 使用签名链接或防盗链 |
| 项目任务书 | 受控 | 未登录只看介绍；正式任务书需登录且参与/解锁 |
| 项目库/项目模板 | 后台资产 | 管理员全局管理；老师授权编辑；不对前台暴露完整内部结构 |
| 协作空间留言/过程作品 | 私密 | 仅小组成员、负责老师、管理员可见 |
| 报名、联系方式、付费记录 | 严格私密 | 仅管理员；老师默认不可导出 |

## 三、MVP 必做保护机制

### 3.1 权限保护

- 未登录访问受保护 API 返回 401；
- 权限不足返回 403；
- 学习者只能看自己的私密数据和参与小组；
- 老师只能看负责范围内的问题、讲解、项目、小组；
- 管理员拥有全站管理权限；
- 下载、导出、批量操作只给管理员。

### 3.2 下载与导出保护

所有导出动作必须记录：

- 导出人；
- 导出时间；
- 导出类型；
- 导出范围；
- 导出原因；
- 文件保留时长。

高风险导出包括：

- 问题库导出；
- 题目图片批量下载；
- 小讲师原始视频下载；
- 项目成果导出；
- 用户信息导出；
- 付费/退费记录导出；
- 家长联系方式导出。

### 3.3 反扒与反批量抓取

MVP 建议实现：

1. API rate limit：同 IP、同账号、同接口频率限制；
2. 登录态校验：私密数据不出现在未登录 HTML 中；
3. 分页限制：列表接口限制 pageSize，禁止一次性拉全量；
4. 防枚举：ID 使用 cuid/uuid，不使用自增 ID 暴露资源数量；
5. 媒体防盗链：图片/视频 URL 使用签名链接或后端代理；
6. robots.txt：限制搜索引擎抓取后台、个人中心、项目协作空间；
7. sitemap 只包含公开页面；
8. 公开图片加轻水印或品牌角标；
9. 视频封面与分享图加入平台 Logo；
10. 异常访问日志：记录高频抓取行为。

### 3.4 水印与品牌标识

公开成果建议加：

- 数学小讲师联盟 Logo；
- “会思考，爱数学”；
- 类型化封面；
- 分享二维码；
- 不遮挡孩子表达的轻量水印。

不建议在孩子视频中央打大水印，避免破坏观看体验。

## 四、P1/P2 后续增强

P1 可做：

- 管理员导出二次确认；

- 版权监测；
- 商业化课程内容授权系统；
- 项目模板版本版权登记；
- 对外合作 API 审批。

## 五、法律与声明机制

网站应在页脚、注册协议、成果分享确认中包含：

1. 平台项目设计、任务卡、页面内容、课程结构归平台所有；
2. 孩子作品归孩子/家庭所有，平台只在授权范围内展示和传播；
3. 未经许可不得批量抓取、复制、商用平台内容；
4. 公开成果可被分享，但不得篡改、恶意剪辑或用于商业推广；
5. 家长可申请下架公开作品；
6. 平台有权下架存在隐私、安全、版权风险的内容。

- [ ] 私密数据不出现在未登录 HTML；
- [ ] 受保护 API 有 401 / 403；

- [ ] 媒体资源不使用永久裸链；
- [ ] 管理员才有批量导出；

- [ ] 成果广场只展示已审核、已授权公开内容；
- [ ] 公开图片/封面带平台标识；
- [ ] robots.txt 屏蔽后台和私密路径；
- [ ] 页脚有版权与使用声明。
