本阶段重点回答：

3. MVP 必须实现哪些功能；

## 二、阶段2 V2 同步更新清单

本 V1 相比阶段3 V0，重点同步以下阶段2 V2规则：

1. 首页副标题改为“小学低年级孩子的数学共学社区”；标签为“小学1–3年级”。
2. MVP种子用户仍以小学一年级下到二年级上为主，但对外定位预留1–3年级空间。
3. “能力标签”在产品表达中改为“能力观察 / 成长能力记录 / 能力观察项”，避免“给孩子贴标签”的负面感。
4. 审核通过后增加站内通知，复杂推送系统后置。
5. 提交问题页面必须支持上传图片 / 拍照原题；题目图片进入问题题库，OCR/AI识别可后置。
6. 问题增加“我也有这个困惑 / 热度”机制，讲解发布后推送给提问者和加热度同学，小讲师帮助人数包含加热度人数。
7. 项目卡片增加解锁条件、组队状态、有效时长。
8. 免费基础项目也必须高水准；与付费项目区别在复杂程度、老师参与深度、反馈深度，而不是质量高低。
9. 项目成果提交形式细化：照片、短视频、语音+图片、简短文字、项目模板。
10. 结营证书展示孩子收获的能力。
11. 题目/项目认领后增加“请假退出”按钮，自动释放资源；付费项目退出规则需报名前明确。
12. 成果广场增加点赞鼓励和温暖行动号召，但不做排行榜。
13. 三个主身份初始灰色，解锁后点亮；孩子可写一句数学相关自我介绍。
14. 增加邀请分享追踪路径与影响力统计。
15. 分享授权统一改为“价值导向分享范围选择”，不使用冷冰冰授权勾选。

## 三、MVP 产品边界

### 3.1 MVP 必须跑通的四个闭环

#### 闭环一：孩子提问 → 审核 → 展示 → 热度 → 等待小讲师

最小路径：

1. 学习者登录；
2. 点击“我要提问”；
3. 上传题目图片 / 拍照原题；
4. 填写问题标题、年级、知识点、困惑描述；
5. 系统保存题目图片进入问题题库；
6. 系统显示温暖提示；
7. 老师后台审核；
8. 审核通过后进入你问我答列表；
9. 系统给孩子发送站内通知；
10. 其他孩子可点击“我也有这个困惑”为题目加热度；
11. 热度高的问题在可认领列表中适当靠前。

#### 闭环二：小讲师认领 → 48小时上传 → 审核 → 分享范围 → 发布/成长记录

最小路径：

1. 学习者点击“我要当小讲师”；
2. 进入可认领问题列表；
3. 选择题目；
4. 弹出小讲师认领贴士；
5. 确认后锁定题目，开始48小时倒计时；
6. 若无法继续，可点击“请假退出”，题目自动释放；
7. 上传讲解视频；
8. 选择分享范围：
   - A. 只分享给出题的同学；
   - B. 愿意分享给更多同学带来启发；
9. 老师审核；
10. 审核通过后发送站内通知；
11. 若选择B，进入成果广场；若选择A，只给出题人/相关同学和本人可见；
12. 讲解推送给提问者和加热度同学；
13. 小讲师成长护照记录帮助人数。

#### 闭环三：项目解锁/报名 → 组队 → 协作空间 → 成果提交 → 审核/证书/反馈

最小路径：

1. 学习者进入项目营；
2. 查看项目卡片：知识点、能力观察方向、解锁条件、组队状态、有效时长；
3. 满足解锁条件或家长完成付费报名；
4. 进入等待组队状态；
5. 系统显示组队进度，如“第一组已加入2名，还缺1名即可组团”；
6. MVP阶段按报名顺序组队，后续可按能力观察记录组队；
7. 组队成功后系统开启协作台；
8. 小组进行任务卡、留言、过程上传、成果提交；
9. 提交成果时选择分享范围；
10. 老师审核；
11. 审核通过后生成结营证书，记录能力收获；
12. 项目完成后弹出儿童视角反馈问卷；
13. 成果、证书、过程记录可永久回看。

#### 闭环四：成果展示 → 点赞鼓励 → 分享传播 → 影响力记录

最小路径：

1. 审核通过且选择公开分享的成果进入成果广场；
2. 其他孩子/家长可点赞鼓励；
3. 页面展示温暖行动号召，引导提问、当小讲师、参加项目；
4. 成果或成长护照可生成分享图；
5. 邀请链接可记录新同学注册与有效参与；
6. 成长护照记录“影响/激发了多少位小同学”。

## 四、页面原型结构 V1

### 4.1 首页原型

```text
[顶部导航]
Logo 数学小讲师联盟 | 首页 | 你问我答 | 项目营 | 成果广场 | 个人中心

[首屏 Hero]
标题：数学小讲师联盟
Slogan：会思考，爱数学
副标题：小学低年级孩子的数学共学社区
标签：小学1–3年级 / 同伴互助 / 项目制学习 / 低焦虑成长
按钮：我要提问 | 看看孩子怎么学

[平台温暖数据]
已提出 X 个好问题 / 已解答 X 个问题 / X 位孩子参与探索 / X 个小组完成协作

[孩子怎么学]
卡片1 提出真实问题：拍照上传原题，说出哪里想不明白
卡片2 认领一道我能讲的问题：成为小讲师，帮助同学
卡片3 参加一个数学小项目：和伙伴一起观察、测量、表达、提交成果
卡片4 留下自己的成长作品：成果、证书、助人记录进入成长护照

[适合谁 / 不太适合谁]
适合：小学低年级、愿意表达、愿意尝试合作、校内数学较轻松
不太适合：只追求短期提分、只想被动听讲、不接受孩子表达不完美

[你问我答预览]
问题卡片 + 热度 + 已发布讲解预览
按钮：我要提问 / 我要当小讲师 / 进入你问我答

[项目营预览]
免费基础项目 + 付费进阶项目
项目卡展示：知识点 / 解锁条件 / 组队状态 / 有效时长

[精选成果预览]
小讲师视频 / 项目成果 / 点赞鼓励 / 生成分享图

[安全、审核与低焦虑承诺]
发布前审核 / 不做公开排名 / 孩子是真正主角 / 积分和能力细节私密
```

MVP功能要求：

- “我要提问”未登录时弹登录/注册弹窗，登录后返回提交问题流程；
- “看看孩子怎么学”锚点跳转到首页内部模块；
- 首页数据为平台级鼓舞数据，不做排行榜；
- 首页副标题和年级标签按阶段2 V2执行。

- 热度：X 位同学也有这个困惑

- 小讲师昵称 + 星级

- 分享范围标记：公开 / 仅相关同学可见

#### 提交问题页面

字段与组件：

- 问题标题；
- 上传图片 / 拍照原题按钮；
- 拍照提示：请尽量拍清楚完整题目；
- 题目文字补充；
- 年级；
- 知识点；
- “我哪里想不明白”；
- 提交按钮。

系统处理：

- 保存原题图片进入问题题库；
- MVP可先人工/半自动标注；
- OCR/AI识别题目文字、知识点、题型作为后续增强；
- 提交后显示温暖提示；
- 审核通过后发送站内通知。

#### 我要当小讲师流程

1. 点击“我要当小讲师”；
2. 进入可认领问题列表；
3. 点击“我来讲”；
4. 弹出小讲师认领贴士；
5. 确认后锁定题目；
6. 48小时倒计时；
7. 上传视频或点击请假退出；
8. 选择分享范围；
9. 提交审核；
10. 审核通过后通知孩子，并推送给提问者和加热度同学。

#### 分享范围选择

```text
你希望这段讲解帮助谁？

A. 只分享给出题的同学，帮助他/她理解这个问题。
B. 我愿意分享给更多同学，也许能给大家带来一点启发。
```

### 4.3 项目营页面原型

```text
[页面标题]
项目营：用数学完成真实小任务

[项目数据条]
已有 X 位孩子参与 / X 个项目小组完成协作 / X 个项目成果被展示

[免费/付费权益对比]
免费基础项目：高质量、低门槛、适合自主组队完成，老师审核但不默认点评
付费进阶项目：更复杂主题、老师指导、节点跟进、展示与个性化反馈

[免费基础项目区]
项目卡片：
- 项目名称
- 适合年级
- 核心知识点
- 能力观察方向
- 解锁条件：如20积分/30积分/完成1个基础项目
- 组队状态：第一组已加入2名，还缺1名
- 有效时长：解锁后1个月内完成
- 当前状态：可报名 / 组队中 / 进行中 / 已结束
- 已参与人数 / 已完成小组数
- 按钮：查看介绍 / 解锁参加

[进阶项目 / 主题项目营区]
项目卡片：
- 项目主题
- 项目周期或预计有效期
- 前置条件：积分/免费项目完成记录
- 付费报名入口
- 服务内容：老师指导、节点提醒、展示、个性化贡献反馈
- 组队状态

[项目成果预览]
精选项目成果卡片 + 点赞鼓励 + 查看详情
```

#### 付费项目报名弹窗

```text
[付费项目说明]
项目名称 / 适合对象 / 预计周期 / 解锁有效期 / 包含权益 / 退出规则

[报名信息确认]
孩子昵称 / 年级 / 家长联系方式 / 想报名项目

[联系与付款]
老师微信二维码或报名老师联系方式
说明：老师/管理员确认后开通项目权限
```

MVP原则：

- 不只弹付款码；
- 先收集报名意向和家长联系方式；
- 老师/管理员第一时间获得信息；
- 付款后管理员手动开通项目权限；
- 自动支付解锁后置。

### 4.4 项目详情页原型

未登录可见：

- 项目介绍；
- 样例成果；
- 适合谁；
- 需要准备什么；
- 免费/付费权益说明；
- 登录/报名按钮。

登录后可见：

- 报名状态；
- 解锁条件；
- 已有积分/已完成前置项目；
- 组队状态；
- 有效时长；
- 认领/报名入口。

参与 / 解锁后可见：

- 正式任务书；
- 协作空间入口；
- 小组成员；
- 过程记录；
- 成果提交；
- 节点提醒；
- 请假退出按钮。

#### 项目认领贴士

> 这是一次真实的数学小项目。认领后，请尽量认真参与；如果有特殊情况，可以请家长帮忙说明。正常请假退出不会被责备；无故退出累计3次后，将暂停一段时间的免费项目认领资格。完成项目后，你可以获得结营证书，并记录到成长护照。

#### 请假退出规则

- 免费项目：请假退出释放名额；正常请假不计入无故退出；无故退出累计3次暂停体验。
- 付费项目：报名前展示退出规则；项目开始前可取消/延期；开始后请假退出可扣除一半费用；无故退出或长期不参与可扣除本次项目全部费用。MVP可人工处理退款/扣费。

### 4.5 项目协作空间原型

```text
[项目标题区]
项目名 / 当前阶段 / 有效期剩余 / 小组成员 / 请假退出

[老师公告区]
项目目标 / 本周任务 / 注意事项

[任务卡片区]
任务1：观察/测量
任务2：画图/记录
任务3：讨论/讲解
任务4：整理/上传
状态：未开始 / 进行中 / 已完成

[小组留言区]
文字留言 / 图片上传 / 系统提醒 / 老师提醒

[作品上传区]
上传草稿 / 照片 / 短视频 / 语音+图片 / 简短文字

[项目进度区]
已加入 → 已组队 → 已分工 → 已提交草稿 → 已完成作品 → 老师已审核 → 已结营

[成果提交区]
提交最终成果
选择分享范围：
A. 只保存在我的成长护照和项目小组记录中
B. 愿意分享给更多同学和家长，展示我们小组的数学探索

[项目完成反馈]
儿童视角反馈问卷入口
```

MVP做：

- 老师公告；
- 任务卡；
- 小组留言；
- 上传照片/视频/语音+图片/简短文字；
- 进度状态；
- 成果提交；
- 请假退出；
- 后台留痕；
- 儿童视角反馈问卷。

MVP不做：

- 实时在线协作文档；
- AI自动贡献分析；
- 复杂群聊；
- 自动退款；
- 视频会议。

```text
[页面标题]
成果广场：看见孩子真实的数学表达和项目探索

[公开数据区]
X 个问题被解答 / X 个项目成果 / X 位孩子参与协作

[筛选区]
成果类型：讲解视频 / 项目成果
知识点 / 项目主题 / 年级

[成果卡片]
- 成果标题
- 类型：讲解视频 / 项目成果
- 孩子昵称
- 主身份 + 星级
- 审核通过标记
- 公开分享标记
- 点赞鼓励按钮
- 查看详情
- 生成分享图

[成果详情页]
视频或作品内容
作品说明
孩子身份卡片入口
相关问题 / 相关项目
点赞鼓励
行动号召贴士
分享按钮
```

#### 点赞规则

- 点赞是感谢和鼓励，不是排名；
- 不做点赞排行榜；
- 不出现“最高赞”“最火作品”；
- 点赞可进入创作者成长记录或影响力记录。

#### 行动号召贴士

- “你也可以提出一个好问题，让小讲师来帮你。”
- “如果你也有不同想法，可以去认领一道题，讲出你的方法。”
- “看完这个项目，你也想和小伙伴一起试试吗？”

## 五、核心状态流转 V1

### 5.1 问题状态

```text
草稿 → 已提交 → 待审核 → 已通过/已退回 → 待认领 → 已认领 → 已讲解 → 已推送给相关同学 → 已关闭
```

补充字段：

- 原题图片；
- OCR识别文本（P1）；
- 知识点；
- 热度人数；
- 加热度用户列表；
- 是否已推送讲解。

### 5.2 讲解状态

```text
已认领 → 48小时倒计时 → 待上传 / 请假退出 / 超时释放 → 已上传 → 待审核 → 已发布/已退回 → 成长记录已更新
```

补充规则：

- 请假退出释放题目；
- 超时未上传自动释放题目；
- 分享范围决定是否进入成果广场；
- 帮助人数 = 提问者 + 加热度人数。

### 5.3 项目参与状态

```text
可查看 → 待解锁 → 已解锁/已报名 → 待组队 → 已组队 → 协作台开启 → 进行中 → 已提交成果 → 待审核 → 已结营/需修改/请假退出/已失效
```

补充规则：

- 项目可有积分/前置项目/付费解锁条件；
- 组队成功后开启协作台；
- 项目有有效时长；
- 完成后永久回看；
- 请假退出和无故退出分开记录。

### 5.4 成果公开状态

```text
仅个人/小组记录 → 愿意公开 → 待审核 → 审核通过公开 → 已生成分享图 → 可撤回/下架
```

### 5.5 身份点亮状态

```text
灰色未点亮 → 已完成有效行为 → 审核通过 → 身份点亮 → 星级成长
```

## 八、温暖提示语文案库 V1

### 8.1 文案标准

沿用阶段3 V0标准：温暖提示语不是简单夸孩子，而是网站教育气质的一部分。以《教育的目的》理念为基底：让孩子在真实经验中产生兴趣、形成理解、学会运用，并在表达、探索和合作中感到知识是活的。

### 8.2 新增场景文案

#### 审核通过通知

- “你的问题已经通过审核啦，正在等待小讲师来帮助你。”
- “你的讲解已经通过审核，可以帮助更多同学啦。”
- “你们小组的项目成果已经通过审核，已经记录到成长护照里。”

#### 热度场景

- “原来不止你一个人有这个困惑。谢谢你把问题说出来，帮助大家一起看见它。”
- “已经有 X 位同学也想弄明白这个问题，等待一位小讲师来点亮思路。”

#### 请假退出场景

- “谢谢你认真说明情况。题目会重新开放给其他小讲师，你以后还可以继续尝试。”
- “项目先暂停也没关系，重要的是诚实说明和认真对待。”

#### 点赞鼓励场景

- “你的鼓励已经送到啦，也许这会让小创作者更有勇气继续表达。”

#### 邀请影响力场景

- “你的分享让更多同学看见了数学可以这样学。”
- “你已经影响了 X 位小同学加入数学小讲师联盟。”
