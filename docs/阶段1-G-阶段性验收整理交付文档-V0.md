## 1. 阶段目标

阶段1-G的核心目标是：

> 公开内容低门槛浏览；真实互动必须登录注册并绑定身份。

- **公开浏览开放**：首页、成果广场、你问我答公开列表、问题详情、项目营公开简介。

## 3. 本次阶段性验收中新发现并修复的问题

阶段性验收不是只写总结文档，本轮重新跑公网 smoke 时发现一个真实线上风险：

```text
/qa 页面中部分 Next Link 登录入口被渲染成：
/math-young-lecturer/math-young-lecturer/login?callbackUrl=...
```

原因：

- Next.js `Link` 会自动加 `basePath`；
- 代码里又手动把 `/math-young-lecturer/login` 写进 `Link href`；
- 因此线上生成了重复 basePath。

处理：

- 修复 `/qa`、`/qa/question/[id]`、`/projects/[id]` 中使用 `Link` 的登录跳转；
- `Link href` 改为应用内路径 `/login?...`；
- `callbackUrl` 仍保留完整部署路径 `/math-young-lecturer/...`；
- 更新 P0-2/P0-3 规则测试，明确防止 Next Link 再次生成 double-base URL。

修复提交：

```text
a0aeee2 stage1g: fix login callback base path
```

本次修复已重新 build、部署并公网验证。
