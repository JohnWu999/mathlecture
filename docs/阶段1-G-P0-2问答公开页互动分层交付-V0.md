> 交付时间：2026-06-09 17:48 CST  
> 阶段原则：公开内容可以浏览；真实互动必须登录注册。

---

## 1. 本轮目标

P0-2 聚焦 `/qa` 问答公开页与 `/qa/question/[id]` 问题详情页：

```text
未登录用户可以继续浏览公开问题列表和问题详情；
但加热度、认领、提交讲解、采纳讲解等真实互动必须清楚标记为“登录后参与”，并保留登录回跳。
```

本轮不是收紧公开阅读权限，而是把“看内容”和“产生真实运营数据”分开。

---

## 2. 代码变更

### 2.1 `/qa` 问答公开页

文件：`app/qa/page.tsx`

已调整：

1. `useSession()` 读取 `status`，区分 loading、未登录、已登录；
2. 顶部说明改为：

```text
公开浏览不需要登录；真实互动需要登录。
```

3. 未登录时：
   - 主按钮显示“登录后提问”；
   - 认领入口显示“登录后认领”；
   - 每个问题的热度按钮显示“登录后加热度”；
   - 登录链接保留 callback：`/math-young-lecturer/login?callbackUrl=/math-young-lecturer/qa` 或 `/math-young-lecturer/qa/ask`。
4. 已登录时：保留原有提问、认领、加热度真实操作能力。
5. 未登录点击热度不再静默跳转，而是先通过页面内文案说明登录原因：避免重复计数，方便老师看见真实需求。

### 2.2 `/qa/question/[id]` 问题详情页

文件：`app/qa/question/[id]/page.tsx`

已调整：

1. 增加登录分层说明卡片：

```text
公开浏览不需要登录
真实互动需要登录
```

2. 未登录时：
   - 热度按钮显示“登录后加热度”；
   - 认领按钮显示“登录后认领这道题”；
   - 讲解提交区域显示“登录后提交讲解”；
   - 登录链接保留当前问题详情 callback：`/math-young-lecturer/login?callbackUrl=/math-young-lecturer/qa/question/[id]`。
3. 已登录时：保留原有真实操作：加热度、认领、已认领后提交讲解、提问者采纳讲解。
4. 未登录点击交互时不再直接静默跳转，而是页面内解释：为什么认领、热度、讲解提交需要绑定账号。
