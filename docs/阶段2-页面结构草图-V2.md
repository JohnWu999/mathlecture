# 阶段2：页面结构草图 V2

项目：数学小讲师联盟  
当前阶段：阶段2｜页面结构草图  
版本：V2  
状态：已合并犟爸确认的 12 个需求问题 + 3 个新增体验想法，作为下一步页面原型与 MVP 需求依据  
依据：阶段1最终交付文档 V1、分页内容清单 V2、删除项说明 V7、阶段2讨论确认项

---

## 一、阶段2目标

阶段2不是写最终页面文案，也不是马上进入代码实现，而是先回答：

1. 每个主页面承担什么任务？
2. 每个页面上放哪些核心模块？
3. 哪些功能是页面内入口，哪些是弹窗或子页面？
4. 未登录、学习者账号、老师账号、管理员账号分别看到什么？
5. 首页按钮、导航入口、成果展示、个人中心如何相互连接？

阶段2完成后，才能进入：

- 页面原型；
- 交互细化；
- 组件拆分；
- MVP 代码重构。

## 二、阶段2新增需求总则

本 V2 版本将犟爸确认的 12 个需求问题，以及后续新增的 3 个体验想法，纳入页面结构与 MVP 需求设计。

### 2.1 三条产品气质原则

1. **有规则，但不冷冰冰**  
   认领项目、认领题目、公开展示、项目退出都需要清楚规则，但表达方式要像“小约定”和“温暖提醒”，避免处罚感、训诫感。

2. **有数据，但不制造比较焦虑**  
   公开页面可以展示平台整体数据、项目参与人数、问题解答数量、协作小组数量，用来鼓舞参与；但不展示个人排名、公开积分、谁超过谁。

3. **有荣誉感，但尊重授权**  
   成果、成长护照、年度感谢长图可以生成分享图，帮助孩子获得成就感；但公开分享必须经过孩子意愿、家长确认和老师审核。

### 2.2 本轮新增需求清单

1. 项目卡片增加“核心知识点 / 能力标签”。
2. 项目认领前增加“认领贴士 / 小约定”。
3. 协作空间尽量覆盖站内交流、留痕、存档，智能分析后置。
4. 小讲师认领题目前增加认领贴士，含 48 小时上传与自动释放规则。
5. 视频 / 项目成果提交页增加“愿意公开分享”授权选项。
6. 成长护照增加助人、合作、项目参与等数据总结。
7. 孩子资料卡支持头像功能：系统头像优先，真实头像可后置并需审核。
8. 项目协作形式采用“结构化协作空间”：留言 / 任务卡 / 上传 / 进度，而不是 MVP 直接做复杂在线文档。
9. 首页首屏按钮确定为“我要提问 / 看看孩子怎么学”。
10. “我要讲题”在问答场景中改为“我要当小讲师”。
11. 管理后台增加付费项目权限授权：MVP 先做管理员手动开通，自动支付解锁后置。
12. 老师工作台需要看到项目组队、完成情况和重要节点。
13. 全站关键动作后增加温暖提示语。
14. 公开展示页面增加平台级 / 项目级数据展示。
15. 成果展示页、成长护照、年度感谢记录增加生成长图与分享能力。

## 三、全站主导航结构

主导航保留 5 个入口：

1. 首页
2. 你问我答
3. 项目营
4. 成果广场
5. 个人中心

不放入主导航：

- 登录 / 注册；
- 上传问题；
- 上传讲解；
- 问题详情；
- 项目任务书；
- 项目协作空间；
- 老师工作台；
- 管理后台。

这些功能不消失，而是作为：

- 场景内按钮；
- 子页面；
- 弹窗；
- 登录后角色后台。

## 四、首页结构草图

### 3.1 首页任务

首页不是完整说明书，而是让第一次进入的家长和孩子在 30 秒内判断：

1. 这是什么？
2. 适不适合我家孩子？
3. 孩子在这里怎么学？
4. 和刷题、补课、AI 答疑有什么不同？
5. 有没有真实成果可以看？
6. 如何开始？

### 3.2 首页模块顺序

建议首页采用 7 个模块：

1. 首屏定位区
2. 孩子怎么学
3. 适合谁 / 不太适合谁
4. 你问我答预览
5. 项目营预览
6. 精选成果预览
7. 安全、审核与低焦虑承诺

---

### 3.3 模块一：首屏定位区

#### 展示内容

- 产品名：数学小讲师联盟
- Slogan：会思考，爱数学
- 副标题：小学低年级孩子的数学小讲师共学社区
- 标签：小学 1–2 年级｜同伴互助｜项目制学习｜低焦虑成长

#### 首屏按钮

建议保留两个按钮：

1. **我要提问**
2. **看看孩子怎么学**

#### 按钮指向

| 按钮 | 指向 | 未登录处理 | 说明 |
|---|---|---|---|
| 我要提问 | 你问我答中的提交问题流程 | 弹出登录 / 注册 | 明确行动入口 |
| 看看孩子怎么学 | 首页内部“孩子怎么学”模块 | 不需要登录 | 理解型入口，不跳复杂页面 |

#### 首页可展示的平台温暖数据

首屏或“孩子怎么学”模块附近可轻量展示平台整体数据，用来鼓舞参与，而不是比较个人：

- 已有多少个好问题被提出；
- 已有多少个问题被小讲师解答；
- 已有多少位孩子参与过项目探索；
- 已有多少个小组完成协作。

文案示例：

> 已经有很多孩子在这里提出问题、讲清思路、一起完成数学小项目。下一个好问题，也许就来自你。

### 3.4 为什么首屏不直接放“我要讲题”？

因为新用户刚进入首页时，可能还不知道：

- 讲什么题？
- 是讲自己的题还是别人的题？
- 讲完谁看？
- 是否有老师审核？
- 孩子讲错怎么办？

所以首页首屏采用：

- 一个行动按钮：我要提问；
- 一个理解按钮：看看孩子怎么学。

“我要讲题 / 我要当小讲师”应该放在用户理解机制之后，出现在“你问我答”板块和“你问我答”页面中。

---

### 3.5 模块二：孩子怎么学

这是“看看孩子怎么学”按钮跳转的位置。

建议用 4 张流程卡片，不写成长文：

1. **提出真实问题**  
   孩子把自己想不明白的问题提交上来。

2. **认领一道我能讲的问题**  
   孩子选择一个自己能讲清楚的问题，成为小讲师。

3. **参加一个数学小项目**  
   和同伴一起完成测量、统计、图形、规律等探索任务。

4. **留下自己的成长作品**  
   通过审核的讲解和项目成果进入成长记录，也可能展示在成果广场。

#### 页面表现

- 用横向流程图或 2×2 卡片；
- 每张卡片配一个图标；
- 每张卡片只写一句解释；
- 不展示完整规则；
- 每张卡片下可放小入口：去提问 / 去认领 / 看项目 / 看成果。

---

### 3.6 模块三：适合谁 / 不太适合谁

采用双栏卡片。

#### 适合

- 小学 1–2 年级；
- 校内数学比较轻松；
- 愿意尝试表达、讲题、合作；
- 家长希望孩子发展思维、表达与协作能力。

#### 不太适合

- 主要目标是短期提分；
- 需要大量基础补差；
- 只希望老师单向讲、孩子被动听；
- 不能接受孩子表达中有不完美过程。

---

### 3.7 模块四：你问我答预览

#### 展示内容

- 3 个已审核问题卡片；
- 1–2 个已发布讲解预览；
- 简短说明：孩子提出问题，孩子认领讲解，老师发布前审核。

#### 按钮

- 我要提问；
- 去认领一道题；
- 进入你问我答。

#### 注意

“去认领一道题”可以引导小讲师行为，但放在这里比放在首页首屏更合适，因为用户已经理解了问答机制。

---

### 3.8 模块五：项目营预览

#### 展示内容

- 免费基础项目 1–3 个预览；
- 进阶项目 / 主题项目营样例；
- 项目成果小图；
- 项目营核心说明：不是刷题，而是用数学完成真实小任务。

#### 按钮

- 看看项目营；
- 查看可参加项目。

#### 权限

- 未登录：可看项目介绍和样例；
- 已登录学习者：可看免费项目和已解锁项目；
- 已报名 / 已解锁：可看任务书和协作空间。

---

### 3.9 模块六：精选成果预览

首页只展示少量精选成果，不承担完整成果展示功能。

#### 展示内容

- 2–4 个优秀小讲师视频；
- 2–4 个项目成果；
- 显示孩子昵称、主身份与星级，例如：小安｜小讲师 ★★；
- 不显示积分；
- 不做排名。

#### 按钮

- 进入成果广场。

---

### 3.10 模块七：安全、审核与低焦虑承诺

用 3 张承诺卡片：

1. **发布前审核**  
   问题、讲解和成果公开前经过必要审核。

2. **不做公开排名**  
   不公开积分，不做排行榜，不制造比较焦虑。

3. **孩子是真正主角**  
   孩子提问、讲解、探索；家长只是辅助操作。

## 五、你问我答页面结构草图

### 4.1 页面任务

你问我答是 P0 核心闭环之一，承担：

1. 展示已审核问题；
2. 让孩子提交问题；
3. 让孩子自主认领问题；
4. 展示已发布讲解；
5. 形成提问者和小讲师的成长记录。

### 4.2 页面模块

1. 页面标题与说明
2. 操作入口区
3. 问题列表
4. 已发布讲解列表
5. 问题详情子页面
6. 提交问题流程
7. 认领问题与上传讲解流程

### 4.3 顶部操作入口

建议有两个核心按钮：

1. 我要提问
2. 我要当小讲师

#### 按钮逻辑

| 按钮 | 实际进入 | 说明 |
|---|---|---|
| 我要提问 | 提交问题流程 | 提交后进入轻审核 |
| 我要当小讲师 | 可认领问题列表 | 不是直接上传视频，先选题再讲 |

### 4.4 问题卡片信息

每张问题卡片展示：

- 问题标题；
- 年级 / 主题标签；
- 问题简述；
- 状态：待认领 / 已认领 / 已讲解；
- 提问者昵称与主身份轻展示；
- 按钮：查看详情 / 我来讲。

### 4.5 问题详情子页面

展示：

- 问题完整内容；
- 图片或补充条件；
- 提问者授权展示信息；
- 已有讲解；
- 认领入口。

### 4.6 提交问题流程

步骤：

1. 登录检查；
2. 填写问题标题；
3. 上传题目图片或输入文字；
4. 选择年级 / 主题；
5. 补充“我哪里想不明白”；
6. 提交审核；
7. 审核通过后进入你问我答；
8. 提交成功后显示温暖提示语。

#### 提问后的温暖提示语示例

- “感谢你的好问题，让我们的数学更有趣。”
- “你愿意把想不明白的地方说出来，这就是很棒的数学开始。”
- “一个好问题，可能会帮助很多同学一起想明白。”

### 4.7 我要当小讲师流程

步骤：

1. 进入可认领问题列表；
2. 选择一道问题；
3. 弹出“小讲师认领贴士”，孩子确认后系统自动锁定；
4. 48 小时内上传讲解视频；
5. 超过 48 小时未上传，题目自动释放给其他小讲师；
6. 老师审核数学正确性、表达清晰度、内容安全；
7. 审核通过后发布；
8. 进入孩子成长记录；
9. 提交成功后显示温暖提示语。

#### 小讲师认领贴士

认领前以弹窗形式展示“小约定”：

- 认领后请在 48 小时内上传讲解视频；
- 如果 48 小时内没有上传，题目会自动释放，其他小讲师可以认领；
- 如果确实遇到特殊情况，可以请家长协助说明；
- 无故放弃累计 3 次后，将暂停一段时间的认领资格；
- 讲解视频要尽量清楚：能看到题目、能听清声音、能讲出自己的思考过程；
- 不要求一次讲得完美，重点是愿意思考、愿意表达、愿意帮助别人。

#### 讲解视频提交后的温暖提示语示例

- “感谢你帮助了一个同学解惑。”
- “你把自己的思路讲出来，也让别人多了一种想法。”
- “小讲师不是因为完美才勇敢，而是因为愿意分享思考。”

### 4.8 免费额度与限制

- 每个孩子每周 1–3 个问题提交审核机会；
- 小讲师同一时间最多认领 1 个问题；
- 讲解视频不作为主要付费点评业务；
- 老师免费流程主要负责审核与能力标签。

### 4.9 视频公开分享授权

孩子上传讲解视频时，提交页增加：

> □ 我愿意将这个讲解公开分享到成果广场。  
> 说明：公开前仍需要家长确认和老师审核。

未勾选时，视频只进入个人成长记录和必要的提问反馈，不进入公开成果广场。

## 六、项目营页面结构草图

### 5.1 页面任务

项目营是 P0 的第二个核心闭环，承担：

1. 展示基础项目和进阶项目；
2. 让孩子参与数学项目；
3. 形成探索家身份和项目成果；
4. 承接主要付费业务。

### 5.2 页面模块

1. 项目营介绍区
2. 免费基础项目区
3. 进阶项目 / 主题项目营区
4. 项目成果预览
5. 项目参与规则说明
6. 项目详情 / 任务书 / 协作空间子页面

### 5.3 免费基础项目区

P0 建议开放 1–3 个免费基础项目，成熟后扩展到 1–5 个。

每个项目卡片展示：

- 项目名称；
- 适合年级；
- 项目主题；
- 核心知识点标签，例如：面积、周长、测量、图形分割、统计、规律；
- 能力标签，例如：画图表达、动手制作、小组合作、观察记录、讲清楚思路；
- 预计周期；
- 当前状态：可报名 / 进行中 / 已结束；
- 已参与人数 / 已完成小组数等项目级数据；
- 按钮：查看介绍 / 报名参加。

标签展示原则：每张卡片最多展示 2–4 个核心标签，帮助孩子判断方向，不把卡片变成成人化说明书。

### 5.4 进阶项目 / 主题项目营区

展示：

- 项目主题；
- 项目周期；
- 是否包含同步启动、破冰、中期展示、结营展示；
- 是否包含个性化贡献反馈；
- 解锁 / 报名入口。

### 5.5 项目详情页

未登录可见：

- 项目介绍；
- 样例成果；
- 适合谁；
- 需要准备什么。

登录后可见：

- 报名状态；
- 是否已解锁；
- 任务节奏；
- 提交入口。

参与 / 解锁后可见：

- 正式任务书；
- 协作空间；
- 小组成员；
- 过程记录；
- 成果提交；
- 节点提醒。

#### 项目认领 / 报名前的小约定

点击报名或认领项目前，弹出“认领贴士”：

- 认领项目后，请认真参与，不要随意退出；
- 如果确实有特殊情况，可以请家长帮忙说明；
- 无故退出累计 3 次后，将暂停一段时间的免费项目认领资格；
- 完成项目后，可以获得项目结营证书，并记录到成长护照；
- 免费项目主要鼓励自主体验；付费项目会有老师指导、节点提醒和个性化反馈。

按钮：

- 我知道了，开始认领；
- 我再想想。

### 5.6 免费项目协作空间

免费项目不默认老师组织线上视频会，而采用异步轻协作：

- 老师公告区：项目目标、本周任务、注意事项；
- 任务卡片区：谁负责观察、画图、讲解、整理等；
- 小组留言 / 聊天区：支持文字、图片、必要时家长辅助输入；
- 作品上传区：草稿、图片、视频、文档；
- 项目进度区：已加入、已分工、已提交草稿、已完成作品、老师已点评、已结营；
- 成果墙；
- 自动结营证书。

MVP 阶段不优先做复杂在线协作文档；先用“留言 / 任务卡 / 上传 / 进度”的结构化协作空间完成站内闭环。所有核心交流、提交、点评、节点记录都应能在后台留痕和存档。AI 智能分析作为后续增强。

### 5.7 项目退出与机会冷却

- 正常请假 / 正常取消不惩罚；
- 无故退出 / 长期不提交计入项目参与记录；
- 累计 3 次后暂停新的免费体验项目机会；
- 不公开羞辱，不叫黑名单。

### 5.8 项目成果公开分享授权

项目成果提交页增加：

> □ 我愿意将这个项目成果公开分享到成果广场。  
> 说明：公开前仍需要家长确认和老师审核。

项目提交成功后的温暖提示语示例：

- “谢谢你和伙伴一起完成了一次真正的数学探索。”
- “你留下的不只是答案，还有观察、尝试和合作的过程。”
- “这个项目会记录在你的成长护照里。”

## 七、成果广场页面结构草图

### 8.1 页面任务

成果广场是独立展示舞台，承担：

1. 展示已审核、已授权、无隐私风险的孩子成果；
2. 给家长建立信任；
3. 给孩子留下作品被看见的舞台；
4. 但不做排名、不做积分比较。

### 7.2 页面模块

1. 页面标题与说明
2. 筛选区
3. 小讲师视频成果
4. 项目成果
5. 孩子身份卡片弹窗
6. 进入相关页面的入口
7. 平台级 / 项目级数据展示
8. 成果分享入口

### 7.3 成果卡片信息

每张成果卡片展示：

- 成果标题；
- 成果类型：讲解视频 / 项目成果；
- 孩子昵称；
- 当前相关主身份和星级，例如：小语｜探索家 ★★；
- 简短成果说明；
- 审核 / 授权标记；
- 查看详情按钮；
- 分享按钮 / 生成分享图入口。


### 7.4 公开数据展示

成果广场可以展示鼓舞型数据，例如：

- 已有多少个问题被解答；
- 已有多少个项目成果被展示；
- 已有多少位孩子参与过协作；
- 某个项目已有多少人参与、多少个小组完成。

边界：展示平台级、项目级、群体级数据，不展示个人排名，不写“超过了多少人”。

### 7.5 成果分享功能

成果详情页支持生成适合保存和转发的分享图：

- 视频讲解成果卡；
- 项目成果卡；
- 结营证书图；
- 成长护照阶段摘要图。

分享图内容应只包含已授权公开的信息：孩子昵称 / 头像或系统头像 / 作品标题 / 主身份星级 / 简短感谢或鼓励语 / 平台标识。

移动端支持长按保存图片；桌面端支持下载图片。

### 7.6 不展示内容

成果广场不展示：

- 具体积分；
- 排名；
- 未授权个人信息；
- 细颗粒能力徽章；
- 老师后台标签；
- 未审核内容。

## 十一、老师审核工作台结构草图

### 11.1 入口

老师工作台不出现在普通学习者导航中。

老师账号点击“个人中心”后进入老师工作台。

### 11.2 模块

1. 待审核问题
2. 待审核讲解视频
3. 待审核项目成果
4. 能力标签勾选
5. 退回原因模板
6. 审核记录
7. 异常提醒
8. 项目管理入口
9. 项目组队信息
10. 项目完成情况
11. 重要节点提醒
12. 公开授权审核

### 11.3 老师审核原则

免费流程中老师主要负责：

- 内容安全；
- 数学正确性；
- 表达是否基本清楚；
- 是否适合公开；
- 勾选能力标签；
- 必要时选择退回原因。

### 11.4 项目管理视图

老师工作台中的项目管理视图至少需要看到：

- 项目名称、当前参与人数、已组队情况；
- 每组成员、分工情况、最近一次互动时间；
- 已上传材料、当前项目阶段、是否卡住；
- 待老师点评 / 待审核 / 待结营的项目；
- 异常提醒：长时间无互动、节点逾期、成果待审核、题目认领 48 小时未上传。

### 11.5 免费流程边界

不默认提供：

- 长篇个性化点评；
- 一对一讲法指导；
- 多轮问题改写服务；
- 每个免费项目的详细人工总结。

## 十二、管理员后台与权限授权

### 12.1 入口

管理员账号点击“个人中心”后进入管理后台，不在普通学习者导航中展示。

### 12.2 MVP 阶段权限授权

MVP 阶段建议先做“管理员手动开通付费项目权限”，不优先接完整支付系统。

后台用户列表至少展示：

- 家长账号 / 手机号 / 联系方式；
- 孩子昵称 / 年级；
- 当前已开通项目；
- 可手动开通项目 A / 项目 B / 项目营；
- 开通时间、到期时间；
- 备注；
- 操作：开通、关闭、延期。

### 12.3 后续自动支付解锁

规模化后再接入微信支付 / 支付宝 / 订单系统，实现付款后自动解锁项目权限。

原则：MVP 先保证业务闭环和运营可控，自动支付解锁作为第二阶段。

## 十四、阶段2已确认需求与待细化问题

### 14.1 已确认进入需求设计的内容

1. 首页首屏按钮最终定为“我要提问 / 看看孩子怎么学”。
2. “看看孩子怎么学”跳到首页内部流程模块，不做单独页面。
3. 问答场景中使用“我要当小讲师”，不再使用“我要讲题”作为主要表达。
4. 项目卡片展示核心知识点与能力标签。
5. 项目和题目认领前均设置温暖的小约定 / 认领贴士。
6. 小讲师认领题目后 48 小时内上传，超时自动释放。
7. 无故退出 / 放弃累计 3 次后，暂停一段时间的免费认领资格。
8. 协作空间尽量站内完成，MVP 先做结构化协作空间并完整留痕。
9. 视频和项目成果提交页增加“愿意公开分享”选项。
10. 成长护照增加助人记录、合作记录和数据总结。
11. 孩子资料卡增加头像能力：MVP 优先系统头像，真实头像后置审核。
12. 公开展示页增加平台级 / 项目级数据展示，用于鼓舞参与但不制造排名。
13. 成果页、成长护照、年度感谢记录支持生成长图和分享。
14. 管理后台支持管理员手动开通付费项目权限，自动支付解锁后置。
15. 老师工作台展示项目组队、完成情况和重要节点。
16. 全站关键动作后增加温暖提示语，让产品有温度。

### 14.2 下一步仍需细化的问题

1. 温暖提示语需要建立一套统一文案库，覆盖提问、认领、上传、审核通过、被退回、项目完成、获得感谢等状态。
2. 公开数据展示需要确定第一批统计口径：平台总数、项目参与数、问题解答数、协作小组数。
3. 分享长图需要确定视觉模板：成长护照图、讲解成果图、项目成果图、年度感谢图。
4. 权限系统需要和现有账号 / 数据库结构对齐，确定“项目解锁”的数据模型。
5. 老师工作台需要拆成 MVP 状态表和后续智能分析版本。
