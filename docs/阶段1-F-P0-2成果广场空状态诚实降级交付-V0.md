# 阶段1-F｜P0-2 成果广场空状态诚实降级交付 V0

更新时间：2026-06-09 11:22 CST

## 1. 本轮目标

处理阶段1-F 第一轮审计中发现的 P0-2 问题：公网 `/api/hall` 当前返回 `outcomes: []`，成果广场页面虽然可访问，但第一批试运营没有公开授权成果时，用户容易感到“空壳页面”。

本轮目标不是伪造作品，也不是导入未经授权的孩子内容，而是在公开侧给出诚实、可理解、可继续行动的空状态：

1. 明确第一批试运营作品正在老师审核与家长/孩子授权确认中；
2. 明确成果广场只展示老师审核通过、且获得公开授权的真实作品；
3. 明确不会展示未经授权的孩子作品；
4. 保留成果广场后续展示真实成果的接口与权限边界；
5. 给用户一个真实下一步入口，而不是空白页面或假成果。

## 2. 根因判断

P0-2 根因不是路由不可访问，也不是成果查询条件错误，而是公开空状态表达不足：

- 线上 `/api/hall` 返回 200，但 `outcomes: []`；
- API 仅返回 `authorizationRule` 与 `rankingEnabled:false`，没有可供前端展示的全局空状态元信息；
- 页面只显示较短的分类空文案，未明确“第一批试运营作品审核中 / 未授权不展示 / 不伪造作品”；
- 如果直接塞入 demo/mock 作品，会违反阶段1-F“入口真实性”原则，也会触碰孩子作品公开授权边界。

## 3. 本轮代码修改

### 3.1 规则层：统一成果广场空状态

文件：`lib/outcome-hall-ui-rules.mjs`

新增：

- `OUTCOME_HALL_EMPTY_STATE`
- `getOutcomeHallEmptyState({ totalPublicOutcomes })`

公开空状态文案口径：

- 标题：`第一批试运营作品正在审核中`
- 说明：成果广场只展示老师审核通过、并获得孩子/家长授权公开的真实作品；当前第一批作品仍在审核与授权确认中，不展示未经授权的孩子作品。
- 主行动：回到你问我答，提出一个问题。
- 跳转：`/math-young-lecturer/qa`

同时更新 `getOutcomeEmptyCopy()`，让问题 / 讲解 / 项目三个分类空状态都保留“审核 + 授权 + 不展示未经授权内容”的边界。

### 3.2 API 层：返回 emptyState 元信息

文件：`app/api/hall/route.ts`

新增 API 返回字段：

```json
{
  "emptyState": {
    "state": "REVIEWING_FIRST_BATCH",
    "title": "第一批试运营作品正在审核中",
    "description": "成果广场只展示老师审核通过、并获得孩子/家长授权公开的真实作品；当前第一批作品仍在审核与授权确认中，我们不会展示未经授权的孩子作品。",
    "primaryActionLabel": "回到你问我答，提出一个问题",
    "primaryActionHref": "/math-young-lecturer/qa"
  }
}
```

保持原授权过滤边界不变：

- 讲解成果仍要求 `status=APPROVED`、`reviewStatus=APPROVED`、`shareScope=PUBLIC_HALL`；
- 项目成果仍要求 `reviewStatus=APPROVED`、`shareScope=PUBLIC_HALL`；
- 仍调用 `canEnterOutcomeHall()` 二次过滤；
- 不展示 `PENDING`、`GROUP_ONLY`、`QUESTION_AUTHOR_ONLY`、`WITHDRAWN` 内容。

### 3.3 页面层：渲染诚实空状态卡片

文件：`app/hall/page.tsx`

修改：

- `HallData` 增加 `emptyState?: OutcomeHallEmptyState`；
- 接收 `/api/hall` 返回的 `emptyState`，无返回时使用 `OUTCOME_HALL_EMPTY_STATE` 兜底；
- 当 `visibleOutcomes.length === 0` 时，不再只显示一句短空文案，而是展示完整空状态卡片：
  - 标题；
  - 说明；
  - 二级提示；
  - 真实跳转按钮。
