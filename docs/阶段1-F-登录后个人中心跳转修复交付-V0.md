# 阶段1-F｜登录后个人中心跳转修复交付 V0

时间：2026-06-09 06:35 CST

## 1. 用户反馈

犟爸反馈：手机端点击【个人中心】后会出现登录页，但填写账号并登录后，依然进入错误页面。

## 2. 根因定位

本轮确认问题不在“入口是否能打开登录页”，而在“登录成功后的跳转链路”。

线上登录页 JS 中仍存在学生登录后按角色得到 `/profile`，然后执行客户端路由跳转：

`router.push(getPostLoginRedirectPath(session?.user?.role))`

对学生账号而言，`getPostLoginRedirectPath(STUDENT)` 返回 `/profile`。这会让手机端登录成功后重新进入客户端路由/RSC 预取/旧 chunk 缓存链路，导致犟爸看到“登录后仍出错”。

因此上一轮把导航入口和项目营按钮改成 `/math-young-lecturer/profile` 还不够，登录表单内部成功回调也必须改。

## 3. 代码修复

修改文件：

1. `app/login/page.tsx`
   - 引入 `PUBLIC_PROFILE_HREF`；
   - 登录成功后先计算 `redirectPath`；
   - 如果 `redirectPath === "/profile"`，使用：
     `window.location.assign(PUBLIC_PROFILE_HREF)`；
   - 即学生账号登录成功后完整加载：
     `/math-young-lecturer/profile`；
   - 老师/管理员仍保持原来的角色工作台跳转逻辑。

2. `tests/stage1f-login-redirect-rules.test.mjs`
   - 新增回归测试：学生登录成功不得再盲目 `router.push("/profile")`；
   - 必须使用部署 basePath 下的完整个人中心入口。

代码提交：
