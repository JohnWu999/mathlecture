## 二、客观差距标注

当前代码已经具备基础 Next.js 页面、Prisma schema、认证、问题、回答、项目、小组、老师 API 等雏形，但与最终产品规则相比，仍存在以下关键差距：

1. **身份命名与成长规则未完全同步**
   - 当前代码仍有“项目官”等旧表达，应统一为：提问者 / 小讲师 / 探索家。
   - 星级、能力标签、成长护照规则需要结构化数据支持。

2. **你问我答流程还不够完整**
   - 低年级拍照/语音辅助、系统建议标题、家长验证、热度说明、72 小时认领规则需要落地。

3. **分享授权与成果公开边界需要强化**
   - 必须区分：未审核、已审核未授权、只给出题人/小组、授权公开。
   - 成果广场只能展示已审核 + 已授权公开内容。

4. **项目营规则需要补齐**
   - 免费/付费项目、解锁条件、自动组队、有效期、请假/退出、付费/退费记录，需要数据与页面配合。

5. **老师与管理员权限需要更清晰**
   - 老师负责审核、能力标签、项目过程管理。
   - 管理员负责全局数据资产、导出下载、AI 项目草稿发布、反扒与审计。

6. **视觉系统尚未进入真实前端组件体系**
   - 首页、成果卡、分享海报、项目卡、身份卡应共享 token 和组件，而不是每页单独写样式。

## 批次 5｜项目营 P0 流程

**目标**：支持免费基础项目与付费进阶项目的最小运营。

**修改文件**

- `app/projects/page.tsx`
- `app/projects/[id]/page.tsx`
- `app/groups/[id]/page.tsx`
- `app/api/projects/route.ts`
- `app/api/projects/[id]/register/route.ts`
- `app/api/groups/[id]/messages/route.ts`
- `app/api/teacher/projects/route.ts`

**必须落地**

- 项目卡展示：知识点、解锁条件、组队状态、有效期。
- 免费项目：异步轻协作 + 系统节奏提示。
- 付费项目：咨询/报名信息、人工确认、付费/退费记录。
- 自动组队：MVP 可按报名顺序成组。
- 退出/请假记录：无故退出累计 3 次暂停新体验项目机会。

**验收标准**

- 项目协作空间留痕。
- 免费/付费边界清晰，不承诺免费 1:1 个性化反馈。
- 付费报名不只是匿名付款码，要保留家长联系与人工跟进入口。
