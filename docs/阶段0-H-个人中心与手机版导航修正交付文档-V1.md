# 阶段0-H｜个人中心与手机版导航修正交付文档 V1

时间：2026-06-08 22:38 CST  
线上地址：http://159.75.144.28/math-young-lecturer

## 1. 用户反馈

犟爸要求修复三个问题：

1. 【个人中心】页面现在无法正常打开；
2. 手机版导航栏去掉【分页折叠按钮】；
3. Logo 图再缩小一点，导航栏上的文字靠右对齐。

## 2. 根因判断

### 2.1 个人中心无法正常打开

线上复现结果：未登录访问 `/profile` 会被 middleware 直接拦截并跳转到 `/login`。

这与 `app/profile/page.tsx` 页面本身已有的“请先登录查看个人中心”引导逻辑冲突：页面明明设计了未登录状态，但 middleware 在页面渲染前已经拦截，所以用户感觉【个人中心】页面打不开。

同时，`/api/user/profile` 仍必须保留登录保护，不能把个人资料数据接口公开。

### 2.2 手机版分页折叠按钮

阶段0-G保留了右上角菜单按钮。用户现在明确要求去掉【分页折叠按钮】，因此手机端应只展示两行导航，不再提供折叠菜单按钮。

### 2.3 Logo和文字对齐

阶段0-G Logo 已缩小到 `30px × 20px`，但用户要求再小一点；导航文字需要靠右对齐。

## 3. 本次修正

### 3.1 个人中心页面可直接打开

修改 `middleware.ts`：

- 从 middleware matcher 中移除 `/profile` 与 `/profile/:path*`；
- 让 `/profile` 页面壳层可以正常打开；
- 未登录时由页面显示“请先登录查看个人中心”；
- `/api/user/profile` 仍受 `/api/:path*` 保护，未登录返回 401。

同时修改 `app/api/user/profile/route.ts`：

- 增加 `user` 为空时的 404 保护；
- 避免旧 session / 脏数据导致前端收到 `user: null` 后崩溃。

### 3.2 手机端去掉分页折叠按钮

修改 `components/navbar.tsx`：

- `@media (max-width: 620px)` 下 `.nav-actions { display: none; }`；
- `.menu-button { display: none; }`；
- `.mobile-menu { display: none; }`。

### 3.3 Logo进一步缩小，文字右对齐

手机端：

- Logo 从 `30px × 20px` 调整为 `24px × 16px`；
- 品牌区域右对齐；
- 分页标题行右对齐；
- 保留“你问我答｜项目营｜成果广场｜个人中心”。
