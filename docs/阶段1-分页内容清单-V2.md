## 一、V2 修订依据

本版本基于分页内容清单 V1 与犟爸新的产品疑问修订，重点吸收以下决策：

1. 需要明确区分 **未登录用户能看到什么** 与 **登录后才能看到什么**。
2. 原“问答广场”更名为 **你问我答**，与“成果广场”形成区分，也更有儿童友好感。
3. “成长中心”建议改为 **个人中心**。普通家庭账号登录后显示孩子/家庭的个人中心；老师账号登录后显示老师工作台/老师个人中心。
4. 不单独保留“登录 / 注册”作为主导航分页。登录注册更适合做成弹窗、抽屉或独立路由，但不作为主导航入口。
5. 点击需要登录的操作时，自动弹出登录/注册窗口；登录成功后回到原操作位置。
6. 首页、你问我答、项目营、成果广场可以公开浏览，但公开范围要分层：可以看介绍、精选内容和部分公开列表；提交、认领、参与、查看个人数据必须登录。
7. 项目营不建议直接公开所有项目任务细节，应公开项目营介绍、项目样例和部分公开成果；正式任务书、协作空间、提交入口需登录并具备参与资格。

主导航建议收敛为 5 个入口：

1. 首页

3. 项目营
4. 成果广场
5. 个人中心

说明：

- 家庭账号登录后，点击个人中心进入家庭/孩子共同使用的个人中心。

## 三、登录注册的产品形态

### 1. 登录注册不是主页面，而是全站通用入口

登录注册更适合做成：

- 顶部按钮；
- 弹窗；
- 侧边抽屉；
- 或独立 `/login` 路由。

但不建议作为主导航里的一个“页面”。

原因：

1. 用户不是为了看登录页而来；
2. 用户通常是在某个场景中需要登录，例如提问、认领、参加项目、查看个人中心；
3. 弹窗登录可以让用户完成登录后回到原场景，减少跳出；
4. 主导航应该呈现产品价值，而不是呈现账户功能。

### 2. 登录触发场景

以下操作触发登录/注册弹窗：

- 点击“个人中心”；
- 点击“我要提问”；
- 点击“我要认领”；
- 点击“上传讲解”；
- 点击“参加项目营”；
- 点击“进入项目协作空间”；
- 点击“提交项目成果”；
- 点击“查看我的积分/徽章/任务”；
- 老师访问审核工作台。

### 3. 登录后的角色跳转

- 家庭账号登录后：进入个人中心，或回到刚才被拦截的操作。
- 老师账号登录后：进入老师工作台。
- 管理员账号登录后：进入管理后台。

## 四、未登录 / 已登录可见边界总表

| 页面/模块 | 未登录可见 | 登录后可见/可操作 |
|---|---|---|
| 首页 | 全部公开浏览 | 可直接进入个人化操作入口 |
| 你问我答 | 可看页面介绍、部分公开问题、已公开讲解 | 提交问题、认领问题、上传讲解、追问反馈、查看自己的任务 |
| 项目营 | 可看项目营介绍、项目样例、公开项目成果 | 查看正式任务书、加入项目、进入协作空间、提交项目成果 |

| 老师工作台 | 不公开 | 老师登录后可见 |

## 五、主页面一：首页

**页面任务：**

让首次访问的家长和孩子快速理解：这是什么、适合谁、怎么参与、是否安全可信、有什么成果。

**未登录可见：**

- 产品名称与核心主张；
- 一句话定位；
- 适合谁 / 不太适合谁；
- 孩子怎么参与；
- 你问我答如何运转；
- 安全、质量与反焦虑承诺；
- 精选成果预览。

**登录后增强：**

- 根据家庭账号显示“继续我的问题 / 继续我的项目 / 查看个人中心”；
- 已登录用户点击提问、认领、项目入口可直接进入相应操作；
- 老师账号不进入家庭入口，而进入老师工作台。

**主要入口：**

- 我要提问 → 未登录弹窗，登录后进入你问我答的上传问题；
- 进入你问我答；
- 了解项目营；
- 进入成果广场；
- 个人中心。

## 六、主页面二：你问我答

> 原名：问答广场  
> V2 建议更名：你问我答

**更名理由：**

1. “你问我答”更儿童友好，更像孩子之间真实互助；
2. 与“成果广场”避免两个“广场”并列造成命名重复；
3. 名字本身就表达核心机制：一个孩子问，另一个孩子答；
4. 比“问答广场”更有参与感，弱化平台感。

**页面任务：**

承载完整问答闭环，是免费提问、问题浏览、自主认领、讲解上传、反馈追问的核心场景页。

**未登录可见：**

1. 页面定位：这里可以提出真实数学问题，也可以看到孩子讲题；
2. 公开问题列表的一部分：年级、知识点、题目摘要、状态；
3. 已审核公开的讲解视频；
4. 问答流程说明；
5. 平台规则：提问匿名、无排行榜、老师审核；
6. “我要提问”“我来讲讲”按钮，但点击后需登录；
7. 成果广场入口。

**登录后可见/可操作：**

1. 提交问题；
2. 查看自己提交问题的审核状态；
3. 自主认领待认领问题；
4. 系统锁定已认领问题；
5. 上传讲解视频；
6. 对自己问题的讲解进行反馈：明白了 / 还有疑问 / 需要增援；
7. 查看自己在你问我答中的任务和记录。

**内部入口 / 子功能：**

### 1. 上传问题

入口：你问我答顶部“我要提问”。

登录要求：必须登录家庭账号。

要点：

- 免费注册后即可提交；
- 上传题目图片或输入文字；
- 选择年级/知识点；
- 写一句“我哪里不明白”；
- 提醒不要上传真实姓名、学校、电话、微信、家庭隐私；
- 提交后进入待审核；
- 审核通过后获得小积分并进入你问我答。

### 2. 问题详情

入口：点击问题卡片。

未登录可见：公开题目摘要、知识点、公开讲解。

登录后增强：可认领、可上传讲解、可反馈。

### 3. 上传讲题

入口：认领成功后，从问题详情或个人中心任务进入。

登录要求：必须登录家庭账号。

要点：

- 展示已认领题目摘要；
- 提醒“讲题不是表演，用自己的话讲清楚”；
- 上传讲解视频；
- 可补充草稿纸或步骤说明；
- 提交后进入老师审核；
- 可主动释放题目。

**关键机制：**

- 认领不做老师预审核；
- 点击认领后系统自动锁定；
- 同一时间一道题只允许一个孩子认领；
- 超时未提交、主动释放或审核未通过后重新开放认领；
- 讲解视频通过老师审核后才公开。

## 七、主页面三：项目营

**页面任务：**

承载 PBL 项目营的介绍、任务书、项目协作和成果提交，是与“你问我答”并列的 P0 核心场景页。

**是否公开所有项目？**

不建议公开所有正式项目细节。

建议采用“三层公开”策略：

### 第一层：公开展示

未登录用户可以看到：

- 项目营是什么；
- 为什么适合小学一、二年级；
- 项目营如何培养数学思维、表达、记录、合作；
- 典型项目样例；
- 已公开授权的项目成果；
- 如何参加项目营。

### 第二层：登录后可看

家庭账号登录后可以看到：

- 可报名/可参加的项目列表；
- 项目基础任务说明；
- 自己孩子正在参与的项目；
- 项目进度；
- 老师反馈。

### 第三层：参与后可进入

只有已加入该项目的小组成员可以进入：

- 正式任务书；
- 项目协作空间；
- 小组成员信息；
- 每日任务；
- 过程记录；
- 项目成果提交。

**为什么不公开全部项目任务？**

1. 正式任务书属于项目体验核心，不适合完全公开复制；
2. 小组协作空间涉及孩子隐私和过程记录；
3. 项目营需要一定参与门槛和老师组织；
4. 公开项目样例和成果就足够帮助家长理解价值。

**项目营主要信息项：**

1. 项目营定位：从讲一道题进入共同完成数学项目；
2. 适合对象：愿意合作、表达、记录和动手探索的孩子；
3. 项目形式：2–3 人小组，异步为主，短同步为辅；
4. 项目周期：通常 5 天一个主题项目；
5. 能力目标：数学思维、表达、记录、合作、反思；
6. 示例项目：房间数学地图、对称图形侦探、时间小管家、纸桥承重挑战等；
7. 结果呈现：成果视频、项目报告、徽章、成果广场展示机会。

**内部入口 / 子功能：**

- 项目介绍；
- 项目样例；
- 项目任务书；
- 项目协作空间；
- 项目成果提交。

## 八、主页面四：成果广场

**页面任务：**

作为孩子的作品展览墙，展示已授权公开的小讲师视频、项目成果和成长片段，建立家长信任，也给孩子真实舞台。

**未登录可见：**

1. 已授权公开的小讲师视频；
2. 已授权公开的项目成果；
3. 老师精选点评；
4. 成果分类与筛选；
5. 页面说明：这里不是排行榜，而是作品展览墙；
6. 参与引导：我也想提问 / 我也想讲题 / 我也想参加项目营；
7. 隐私说明：公开内容经过授权和审核。

**登录后增强：**

1. 查看自己的成果是否已发布；
2. 查看自己成果的审核状态；
3. 管理公开授权；
4. 从个人中心进入自己的成果详情。

**呈现原则：**

- 不显示公开积分；
- 不做排行榜；
- 不使用“最强”“第一名”等比较语言；
- 强调真实成长、清楚表达和项目过程。

## 九、主页面五：个人中心

> V1 名称：成长中心  
> V2 建议名称：个人中心

**更名理由：**

1. “个人中心”更符合用户习惯，家长容易理解这是登录后查看自己账号内容的地方；
2. 同一个入口可以根据身份展示不同内容；
3. 家庭账号进入孩子/家庭个人中心；老师账号进入老师个人中心/老师工作台；
4. “成长中心”的含义很好，但可以作为个人中心内部模块名称，例如“成长护照”。

**页面任务：**

作为登录后个人化空间。家庭账号用于家长和孩子共同查看孩子的提问、讲解、项目、积分、徽章、老师反馈和隐私授权；老师账号用于进入审核工作台。

**未登录状态：**

点击“个人中心”不显示空页面，而是弹出登录/注册窗口。

提示语建议：

> 登录后可以查看孩子的提问、讲解、项目、徽章和老师反馈。

**家庭账号登录后显示：**

1. 孩子身份与基础信息：昵称、年级、成长身份；
2. 我的任务：待提交讲解、待修改视频、项目今日任务、待反馈问题；
3. 我的提问：审核中、待认领、已解决、追问中；
4. 我的讲解：已认领、审核中、已发布、需修改；
5. 我的项目：正在参与的项目、历史项目、项目成果；
6. 积分与徽章：积分仅自己可见，徽章可公开展示；
7. 家长设置：老师反馈摘要、隐私授权、公开视频授权、账号信息。

**老师账号登录后显示：**

老师不进入孩子个人中心，而进入老师工作台，内容包括：

1. 待审核问题；
2. 待审核讲解；
3. 待审核项目成果；
4. 退回修改反馈；
5. 异常提醒；
6. 审核记录；
7. 班级/项目管理入口。

**显示规则：**

- 积分只对自己和家长可见；
- 徽章、作品可在授权后公开展示；
- 不显示和其他孩子的排名比较；
- 不出现“落后了”“超过了多少人”等焦虑提示。

## 十、老师工作台 / 审核页

**页面定位：**

老师工作台不是公开主导航页面，而是老师角色登录后从“个人中心”自动进入的后台页面。

**页面任务：**

帮助老师高效审核问题、讲解视频和项目成果，守住数学正确性、内容安全和基本表达清晰度。

**主要信息项：**

1. 待审核问题：安全、完整、适合、重复；
2. 待审核讲解：数学正确、表达基本清楚、视频安全；
3. 待审核项目成果：数学目标、项目过程、成果完整性、安全；
4. 审核结果按钮：通过、退回修改、不适合发布、释放题目、需要增援；
5. 温和反馈模板：给孩子和家长的修改建议；
6. 异常提醒：频繁乱提交、频繁认领释放、可疑互相采纳；
7. 审核记录：保留操作日志。

**审核边界：**

- 老师守数学正确性和安全边界；
- 不把孩子表达改成成人脚本；
- 不以“表演效果”替代“真实理解”；
- 不让未审核内容公开展示。

## 十三、V2 关键结论

### 1. 未登录和登录后看到的内容不一样，必须区分

未登录用户主要看公开介绍、公开成果、部分公开问题和公开讲解；登录后才能提交、认领、参与项目、查看个人数据。

### 2. 项目营可以公开，但不应公开所有正式任务细节

公开项目营介绍、样例和成果；正式任务书、协作空间和提交入口需要登录及参与资格。

### 3. 不需要单独把“登录注册”放进主导航

登录注册应作为弹窗/抽屉/独立路由能力，在用户需要操作时触发。

### 4. “个人中心”比“成长中心”更适合作为导航名

成长中心可以作为个人中心内部模块或视觉标题，例如“我的成长护照”。

### 5. “问答广场”更名为“你问我答”

对孩子更友好，也避免和成果广场命名重复。

## 十四、分页内容清单 V2 验收自检

### 标准1：每个主页面能用一句话说清“用户看到它能理解什么”

- 首页：用户理解产品是什么、适合谁、怎么参与、是否可信。
- 你问我答：用户浏览问题与讲解，登录后完成提问、认领、讲解、反馈。
- 项目营：用户了解项目营，登录/参与后进入任务书和协作空间。
- 成果广场：用户查看已授权公开的孩子成果。
- 个人中心：登录后按角色查看家庭成长记录或老师工作台。

结论：通过。

### 标准2：没有两个主页面表达同一意思

结论：通过。

说明：

- 首页负责总理解；
- 你问我答负责问答闭环；
- 项目营负责 PBL 闭环；
- 成果广场负责公开作品展示；
- 个人中心负责登录后的个人化内容与角色分流。

### 标准3：每个主页面信息项不超过 7 个

结论：通过。每个主页面主要信息项均控制在 7 个以内。
