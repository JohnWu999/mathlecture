## 一、总体判断

这轮反馈说明：第一轮 P0 已让入口“能点、能提交”，但真实用户继续试跑后暴露出第二层闭环问题：

1. **运行时资源不可见**：头像、二维码等上传文件在生产环境写入运行目录后，页面必须能通过稳定路由读回，不能只返回一个前端看似正确但公网不可访问的 URL。
2. **运营时间不能用旧项目创建时间冒充**：项目任务 Day、开始时间、截止时间要从学习者加入小组、开通项目、报名时间等学习者实际开始时间推导。
3. **“查看明细 / 查看具体内容”必须有可感知反馈**：点击后应展开、滚动/聚焦到明细面板，并显示“已展开”的选中状态，避免用户以为点不动。
4. **老师审核素材必须可打开**：讲题视频、作品链接需要转成部署路径下可打开的链接，并提供复制兜底说明。
5. **新学员注册要符合真实招生字段**：年级改为“大班、一年级、二年级、三年级”；地域改为省份+城市；注册后基础参与默认开放。

## 二、本轮已完成的代码修复（本地，尚未部署生产）

### 1. 头像 / 二维码图片上传后页面显示失败

根因判断：上传 API 会把文件写到 `UPLOAD_DIR`，但页面预览使用 `/math-young-lecturer/uploads/...`；生产运行目录下的上传文件不一定在 Next 静态 public 目录中，因此需要运行时读取路由。

已修复：

- 新增 `app/uploads/[kind]/[filename]/route.ts`；
- 显式允许 `avatar`、`consultation-qr` 等上传类型；
- 从 `process.env.UPLOAD_DIR` 读取文件；
- 按扩展名返回 `image/jpeg`、`image/png`、`image/webp` 等 Content-Type；
- 保留安全路径校验，禁止 `..`、斜杠穿越。

### 2. 项目任务卡开始/截止时间不真实、Day 未按今天更新

根因判断：协作空间 API 之前使用 `group.createdAt` 作为开始时间。若项目组或 demo 小组早于真实报名创建，就会显示旧日期，例如 2026-05-22，而不是朵朵昨天报名后的真实开始。

已修复：

- `app/api/groups/[id]/messages/route.ts` 新增 `deriveLearnerProjectStartDate()`；
- 优先使用当前学习者 `membership.joinedAt`；
- 再 fallback 到 `UserProjectAccess.validFrom / createdAt`；
- 再 fallback 到 `ProjectRegistration.createdAt`；
- 最后才使用 `group.createdAt`；
- 新增 `deriveCurrentProjectDay()`，按学习者开始日期与今天计算当前 Day，并返回给前端。

### 3. Teacher / Admin 看板“查看明细”点不动

根因判断：上一版点击会改变 state，但没有滚动、焦点、aria-expanded 或“已展开”反馈，用户感知上等于无效。

已修复：

- 老师工作台新增 `dashboardDetailRef`、`handleSelectDashboardCard()`；
- 管理员后台新增 `countDetailRef`、`moduleDetailRef`、`handleSelectCountCard()`、`handleSelectWorkbenchSection()`；
- 点击后滚动/聚焦到明细面板；
- 按钮增加 `aria-expanded` 和 `aria-controls`；
- 明细面板增加“已展开：xxx”状态提示。

### 4. 老师审核讲题视频、成果作品链接无法查看

根因判断：素材链接可能是运行时上传路径、内部相对路径或完整 URL；审核页直接使用原始值，可能在 basePath 部署下不可打开。

已修复：

- 老师页新增 `normalizeReviewAssetUrl()`；
- 对 `/uploads/...` 等相对路径自动补 `/math-young-lecturer`；
- 保留完整 `http(s)` 外部链接；
- 讲题视频和成果链接都使用规范化后的 href；
- 增加“无法打开时请复制链接到浏览器”的兜底说明。

### 5. 新学员注册字段与基础参与开放

已修复：

- 注册页年级选项改为：大班、一年级、二年级、三年级；
- 新增中国省份+城市选项列表 `lib/china-regions.mjs`；
- 注册页改为省份、城市二级选择；
- 注册 API 接收 `province`、`city`，并合并保存到 `User.region`；
- 新学员注册后 `isActive=true`，默认开放【你问我答】基础参与；
- 注册成功文案改为“已自动开放你问我答基础参与”。

### 6. 免费项目报名不再暗示老师后台审核

已修复：

- 免费项目报名接口对免费项目写入 `CONFIRMED` 状态；
- 返回文案改为“免费项目满人数即可成组，老师工作台只查看学习状态和项目过程”；
- 项目详情页补充说明：免费项目满人数即可成组，老师不做人工作业式审核。

## 五、仍需产品决策 / 后续 P1 处理的事项

本轮没有伪装这些能力已完成：

1. **项目任务解锁与验收标准**：建议做成“任务解锁模式”，每个 Day 有完成标准、提交证据、老师/系统确认，再开启下一天；这属于项目运营规则 + 数据模型升级，建议列为 P1。
2. **最终成果展示形式**：建议支持照片、视频、作品链接三类成果，但进入成果广场前仍需老师审核 + 家长/孩子授权；具体模板需在项目任务设计中确定。
3. **报名意向库归属老师工作台**：本轮先记录为 IA 调整建议。因为报名意向当前牵涉项目权益、咨询二维码、项目包和付费/免费边界，迁移到老师工作台需要重新划分老师可见字段与管理员权限。
4. **各大数据库导出功能**：建议作为管理员 P1 数据运营能力，导出需带权限校验与审计日志，不能只加前端下载按钮。
5. **中国省市完整性维护**：本轮已内置全国省级行政区和主要城市/地区列表；后续可升级为独立数据源或更细粒度区县。
