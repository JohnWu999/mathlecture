# 阶段1-F｜账户退出登录按钮补齐交付 V0

时间：2026-06-09 07:38 CST

## 1. 用户反馈

犟爸确认学生账号现在可以正常登录，同时提出需要补充账户【退出登录】按钮。

## 2. 判断

当前桌面导航中已有登录态退出动作，但：

1. 文案为“退出”，不够明确；
2. 手机端导航在小屏下会隐藏 `.nav-actions`，因此孩子/家长在手机个人中心里缺少一个稳定可见的退出入口；
3. 阶段1-F口径要求主要入口真实可操作，账户切换/退出也应有明确入口和真实动作。

因此本轮不是视觉装饰，而是补齐登录闭环里的“退出登录”真实操作。

## 3. 测试先行

新增规则测试：

```text
tests/stage1f-account-logout-rules.test.mjs
```

覆盖：

- 学生个人中心必须直接导入并调用 NextAuth `signOut`；
- 个人中心必须出现明确文案“退出登录”；
- 退出后回到部署路径下登录页 `/math-young-lecturer/login`；
- 桌面导航中的账户退出按钮也应使用明确文案“退出登录”。

已先运行测试并确认红灯失败，再做实现。

## 4. 代码修改

### 4.1 个人中心新增退出登录按钮

修改：

```text
app/profile/page.tsx
```

在成长护照顶部账户区域新增：

```tsx
<button
  type="button"
  onClick={() => signOut({ callbackUrl: "/math-young-lecturer/login" })}
  className="hand-btn hand-btn-white text-xs mt-4 inline-flex"
>退出登录</button>
```

这保证手机端进入个人中心后，即使顶部导航账户按钮隐藏，也能直接退出当前账号。

### 4.2 桌面导航文案同步

修改：

```text
components/navbar.tsx
```

将原桌面登录态按钮：

```tsx
退出
```

改为：

```tsx
退出登录
```

并将退出后的 callbackUrl 统一为：

```text
/math-young-lecturer/login
```

代码提交：

```text

```
