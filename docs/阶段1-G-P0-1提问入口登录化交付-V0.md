## 1. 本轮目标

阶段1-G的原则是：

> 公开内容可以浏览；真实互动必须登录注册。

P0-1聚焦提问入口：

```text
/qa/ask
```

目标：

1. 未登录用户不能直接看到完整提问表单；
2. 未登录用户先看到“登录后提问”的说明卡片；
3. 文案说明为什么需要登录：老师讲解完成后才能把视频和反馈推送给提问者；
4. 登录 / 注册入口保留回跳 `/qa/ask`；
5. 后端 `POST /api/questions` 继续保持 401 匿名写入保护；
6. “匿名提问”文案改为“匿名展示”，避免误解成无需注册即可提问。

## 2. 修改文件

### 2.1 `app/qa/ask/page.tsx`

已完成：

1. `useSession()` 改为读取 `status`：

```ts
const { data: session, status } = useSession();
```

2. 增加登录状态加载页：

```text
正在确认登录状态...
```

3. 增加未登录登录门槛页：

```text
登录后提问
```

说明文案：

```text
提问需要登录后进行。这样老师讲解完成后，我们才能把讲解视频和反馈准确推送给你，也能把这个问题放进你的成长记录里。
```

4. 未登录态提供两个真实入口：

```text
去登录 / 注册
先浏览公开问题
```

登录入口：

```text
/math-young-lecturer/login?callbackUrl=/math-young-lecturer/qa/ask
```

5. 登录用户仍看到原完整提问表单。

6. 提交时的兜底未登录提示保留，但文案补充“讲解完成后收到反馈”：

```text
请先登录。登录后，我们才能把这个问题放进你的成长记录里，并在老师讲解完成后收到反馈。
```

7. “匿名提问”文案改为：

```text
公开展示时隐藏孩子姓名（后台仍会记录账号，方便老师反馈）
```

这表示：

```text
匿名展示，不是匿名参与。
```

### 2.2 `tests/stage1g-auth-boundary-rules.test.mjs`

新增阶段1-G规则测试，覆盖：

1. `/qa/ask` 必须读取 session status；
2. 未登录态必须在表单之前返回登录门槛页；
3. 未登录态必须出现“登录后提问”；
4. 未登录态必须解释老师讲解完成后可把反馈推送给提问者；
5. 登录链接必须保留回跳 `/math-young-lecturer/qa/ask`；
6. 匿名文案不得再使用“匿名提问（保护提问安全感）”；
7. 匿名文案必须说明“公开展示时隐藏孩子姓名”和“后台仍会记录账号”；
8. `POST /api/questions` 必须检查 session、未登录 401、创建问题时使用 `authorId: session.user.id`。
